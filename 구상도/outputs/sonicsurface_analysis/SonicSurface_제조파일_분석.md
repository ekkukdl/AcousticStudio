# SonicSurface 1.2 제조 파일 분석

분석일: 2026-10-02. 대상: `SonicSurface1.2_2Layers_183x169/Project Outputs for SonicSurface`의 파일 29개.

후속 동박 연결 검증은 [SonicSurface_동박연결_검증.md](SonicSurface_동박연결_검증.md)에 기록했다. 아래 내용은 초기 파일 분석이며, 커패시터 추가 8개의 연결 등은 후속 검증 결과를 참조한다.

이 자료는 10mm 트랜스듀서 256개를 위한 평면 2층 PCB의 제조 출력이다. 회로 동작 방식은 참고할 수 있지만, 16mm·128채널 원통형 배열에는 기구와 PCB 배치를 다시 설계해야 한다. 원본 파일은 변경하지 않았다.

## 2. 상세 BOM과 부품 좌표의 일치

| 부품 | Main.CSV 수량 | 부품 배치 파일 수량 | 해석 |
|---|---:|---:|---|
| Transducer 10mm | 256 | 256 | 16 × 16 배열 |
| 74HC595, SOIC16 | 32 | 32 | 8출력 시프트 레지스터 |
| 듀얼 드라이버, SOIC8 | 128 | 128 | 총 256출력 |
| 0.1µF, 0805 | **168** | **168** | 기본 160개 + 추가 8개 |
| HEADER-2X2 | 2 | 2 | K1, K2 |
| HEADER-2X3 | 2 | 2 | K3, K4 |
| DC 전원 잭 | **2** | **2** | J1, J4 |
| FPGA 연결용 소켓 | 2 | 2 | J2, J3 |
| 합계 | 592 | 592 | 좌표 파일 592행과 일치 |

간략 `BOM.txt`에는 커패시터 160개와 DC 잭 1개가 기록되어 있지만, 이 버전의 상세 제조 BOM과 좌표 파일에는 각각 **168개와 2개**다. 이 기판을 복제할 때는 상세 버전과 실제 패턴을 우선 대조해야 한다.

커패시터 명칭은 C1~C4_SHIFTERS1~32 및 C13_SHIFTERS1~32, 총 160개와 C5~C12, 추가 8개다. 패키지 이름이 `Res 0805 (Vishay)`이지만 값과 설명은 0.1µF 커패시터다. 패키지 이름만 보고 저항으로 구매하지 않는다. 추가 8개의 정확한 전원 연결은 동박 추적 또는 원본 회로도로 확인해야 한다.

드라이버의 상세 BOM Comment는 `IN-MOSDRV-TC1426CPA-8`이고 패키지는 SOIC8이다. 간략 BOM은 MIC4127 및 TC4427A 등의 후보를 설명한다. **라이브러리 Comment를 그대로 확정 구매 품번으로 사용하지 않는다.** 입력·출력 반전, 전압 정격, 핀 배치, 정확한 패키지를 제조사 데이터시트와 대조해야 한다.

별도 외장 MOSFET, 전원 레귤레이터, 큰 전해 커패시터, 저항은 이 상세 BOM에 기록되어 있지 않다. 앞서 작성한 예산의 버퍼·보호회로·전해 커패시터 등은 원통형 분산 배선 설계를 위한 추가 제안이며 원본 BOM을 그대로 옮긴 항목이 아니다.

## 3. 치수와 16mm 부품의 장착 가능성

Gerber의 좌표 형식은 `%FSLAX25Y25*%`, 단위는 inch다. Main.GM1의 사각형 최대 좌표는 X728709, Y663000이므로 외곽 중심선 치수는 다음과 같다.

- X: 7.28709 inch × 25.4 = **185.092086mm**.
- Y: 6.63000 inch × 25.4 = **168.402mm**.

파일명 및 간략 BOM의 183 × 169mm와 다르다. 실제 제조 치수는 외곽층을 CAM에서 확인하고 업체와 합의해야 한다. 제목의 치수만으로 케이스를 설계하지 않는다.

부품 중심 좌표에서 트랜스듀서는 X·Y 각각 16개 위치를 가지며, 인접 중심 간격은 **약 10.5mm**다. 중심 간 전체 길이는 15 × 10.5 = **157.5mm**이고, 10mm 몸체를 포함한 배열 폭은 약 **167.5mm**다.

같은 중심 좌표에 16mm 몸체를 놓으면 인접 부품이 **5.5mm 겹친다**. 따라서 16mm 부품을 기존 기판에 직접 꽂는 방식은 성립하지 않는다. 같은 평면 16 × 16 배열을 간격 16mm로 재설계하면 몸체 포함 최소 폭은 256mm이며 실제로는 조립 여유가 더 필요하다. 이 값은 원통형 설계의 최종 지름을 의미하지 않는다.

`SonicSurface_placement_comparison.png/.svg`는 제공된 부품 중심 좌표를 사용한 비교 그림이다. IC 도형 크기는 설명용 근사이고 양면 좌표를 겹쳐 그렸으며, 동박층의 정확한 CAM 렌더링이나 전기적 연결 검증 결과가 아니다.

## 4. 회로 동작의 해석

파일의 부품 수량과 SHIFTERS1~32 반복 명칭은 아래 8채널 묶음 32개 구조와 일치한다.

```text
PC의 위상 명령 → 별도 FPGA 코어보드
                         ↓ 데이터·시프트·래치 신호
8채널 묶음: 74HC595 1개 → 듀얼 드라이버 4개 → 송신기 8개
                         ↓ 32묶음
                    총 256채널
```

74HC595가 데이터를 8개 출력으로 펼치고 드라이버가 트랜스듀서 구동 전류를 공급한다. ‘MOSFET 드라이버 IC’라는 명칭이 외부 MOSFET을 반드시 추가한다는 의미는 아니다. 위 설명은 참고 아키텍처와 부품 수량에 근거하며, 모든 패드 간 연결을 역추적한 회로도는 아직 작성하지 않았다. J1/J4 및 K1~K4의 핀별 전압·기능은 좌표나 명칭만으로 확정하지 않았다.

별도 Firmware 폴더의 FPGA primary 프로젝트에는 편집 가능한 VHDL과 Quartus 설정이 있다. `.qsf`에 DATA[0]~DATA[31] 및 SHIFT_CLOCK_1/2, LATCH_CLOCK_1/2가 기록되어 있다. SHIFT는 FPGA PIN_28/85, LATCH는 PIN_30/84다. **이 번호는 FPGA 칩 핀 번호이며 PCB 커넥터 번호가 아니다.** 코어보드 회로도와 PCB 패턴을 함께 확인해야 커넥터 연결표를 만들 수 있다.

Masterclock.vhd의 PLL은 입력 주기 20,000ps(50MHz), 배율 128/625로 **10.24MHz**를 생성한다. Mux8.vhd에는 8개 입력을 선택해 하나의 출력으로 보내는 동작이 있다. 기존 32단계·40kHz 방식에서는 8배 시프트와 1.28MHz 출력 갱신을 사용하는 구조다. 파형은 하드웨어에서 측정하지 않았다.

Firmware README에 따르면 배포된 JIC에는 송신기 위상 보정이 포함되지 않는다. 동일한 음향 극성으로 조립하거나 PC 계산/펌웨어에 보정을 반영해야 한다. Primary/Secondary 동기화 역할도 구분되어 있다.

## 5. 제조 전에 발견한 주의점

1. **Pick & Place 부품명이 잘렸다.** C4_SHIFTER, T1_SHIFTER처럼 여러 행에 동일한 이름이 반복된다. 상세 BOM의 전체 참조명과 대응시켜 복원·확인하기 전에는 자동 실장 업체에 검증된 좌표표로 제출하면 안 된다.
2. 좌표표의 면 표시는 **Top 584개 / Bottom 8개**다. Bottom 8개는 모두 하단 왼쪽의 트랜스듀서이고 나머지 트랜스듀서 248개는 Top이다. 실제 장착 의도인지 출력 메타데이터 오류인지 이 파일만으로 확정할 수 없으므로 단면 장착 방향을 확인해야 한다.
3. 드릴 보고서는 총 **1,505개**의 구멍을 기록한다. 1.1999mm 구멍 512개는 256개 송신기의 두 단자 수와 일치한다. 다만 16mm 부품의 핀 간격·핀 지름까지 호환됨을 증명하지 않는다.
4. 드릴 보고서의 0.508mm 구멍 875개, 1.016mm 20개, 1.03988mm 88개, 1.1999mm 512개, 2.54mm 6개, 3.50012mm 4개는 도면·패턴과 대조한다. 88개는 두 44핀 FPGA 소켓의 총 핀 수와 일치한다.
5. 파일은 2018-07-18 생성 출력이다. Gerber 제조 가능 여부와 회로의 전기적 적합성은 별개의 검증이다. 원본 넷리스트·회로도·DRC 결과를 확보한 것은 아니다.

## 6. 128채널 원통형 장치에 적용할 부분

| 항목 | 활용 방법 |
|---|---|
| FPGA의 위상 생성·다중화 방식 | 기반으로 사용 가능. 128채널 전송·채널 순서에 맞춰 검토 |
| 8채널 회로 묶음 | 32묶음에서 **16묶음**으로 구성 |
| 듀얼 드라이버 | 실장 128개에서 **64개** |
| 시프트 레지스터 | 실장 32개에서 **16개** |
| 송신기 실장 위치 | 16mm 곡면 패널의 위치로 재설계 |
| FPGA 핀 연결 | 기존 QSF와 코어보드 자료를 참고하되 새 연결표 필요 |
| 동박·전원·커넥터 | 네 패널 분산 배선에 맞춰 새로 설계 |
| 커패시터 | IC별 기본 80개 + 제안 버퍼 4개 = 84개. 분기용 부품은 별도 설계 |
| 프레임·FPCB | 내경·길이·간격·몸체 높이에 맞춰 새 모델 필요 |

기존 기판을 128개만 실장해 구동 방식을 시험하거나, 출력에서 선을 빼 별도 16mm 프레임으로 연결하는 방식은 검토할 수 있다. 그러나 긴 배선의 부하·귀환·전원 안정성과 미사용 출력 처리를 확인해야 하며, 원판을 절반으로 자르는 방식으로 128채널을 얻을 수 있다고 판단하지 않는다.

권장 진행 순서는 8채널 회로의 핀별 연결과 전원 조건 확정 → 시제품 파형 확인 → 16mm 32개 패널의 간격·법선 방향 확정 → 4패널 128채널 회로/기구 설계다. 이는 다음 설계 작업의 순서이며 이 분석에서 제작용 새 회로도나 원통형 CAD를 완성한 것은 아니다.
