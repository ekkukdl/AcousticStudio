# 8면 평면 PCB 배열 설계 방향

2026-10-04. 사용자 제시 이미지처럼 평면 패널을 다각형 프레임 둘레에 장착하는 구조로 설계 방향을 변경한다. 기존 곡면 FPCB 모델은 이전 검토안으로 보관한다.

## 적용 조건

기존 요청은 16mm 송신기, 128개 독립 채널, Langevin 제외이다. 새 이미지에는 256채널이 표시되어 있으므로 사용자 확인 전에는 기존 128채널 조건을 유지한다. 이미지 치수는 제작 도면으로 확정하지 않는다.

| 항목 | 현재 설계 제안 | 이미지의 256채널 구성 |
|---|---:|---:|
| 패널 수 | 8 | 8 |
| 패널당 송신기 | 16 (2열 × 8개) | 32 (2열 × 16개) |
| 전체 송신기 | 128 | 256 |
| 패널당 8출력 시프트 레지스터 | 2 | 4 |
| 패널당 듀얼 드라이버 | 8 | 16 |
| 전체 시프트 레지스터 | 16 | 32 |
| 전체 듀얼 드라이버 | 64 | 128 |

각 송신기는 드라이버 출력 한 개와 GND로 구동하는 단일 출력 방식 기준이다. 브리지 구동을 채택하면 드라이버 개수가 달라진다. 드라이버는 MIC4127 또는 TC4427A를 검토하되 전압 정격과 실제 구매 부품에 맞춰 회로를 확정한다.

## 기판 및 조립 구조

우선 검토안은 동일한 양면 실장 평면 FR-4 PCB 8장이다. 안쪽 면에 송신기를 관통형으로 납땜하고 바깥쪽 면에 레지스터, 드라이버, 커패시터와 커넥터를 배치한다. 앞/뒤 동박이 있는 양면 기판과 앞/뒤로 부품을 장착하는 양면 실장은 다른 개념이다. 필요한 동박 층수는 배선 및 접지 품질을 검토한 뒤 결정한다.

이미지의 단면처럼 송신기 PCB와 드라이버 PCB를 두 장으로 분리할 수도 있다. 이 경우 패널 내부에 16개 독립 출력과 GND를 연결하는 커넥터/배선 및 스페이서가 추가된다. 정비나 부품 공간을 위해 필요한 경우에 선택한다. 통합 보드는 부품 후면 배선과 송신기 핀 납땜 자리의 간섭을 확인해야 한다.

프레임은 송신기의 하중과 패널 고정을 담당한다. 방사면 앞을 가리는 브래킷은 피하고, 케이블과 전원 커넥터는 바깥쪽에서 접근하게 한다. 각 패널의 장착 각도와 위치는 음향 모델의 좌표와 일치해야 한다.

## 치수 검토

16mm 몸체를 16개 길이 방향으로 배치하면 간격 없이도 256mm가 필요하다. 따라서 이미지의 2×16 배열과 약 200mm 높이는 동시에 만족할 수 없다. 중심 간격 20mm를 가정하면 송신기 부분 길이는 `(16-1)*20+16 = 316mm`이며, 기판 끝 여유 및 커넥터는 추가된다.

128채널의 2×8 배열에서는 같은 중심 간격일 때 송신기 부분 길이가 `(8-1)*20+16 = 156mm`다. 가로 중심 간격 18mm를 가정하면 송신기 부분 폭은 `18+16 = 34mm`다. 기판 40×180mm는 배치 검토용 후보로 삼을 수 있으나, 고정홀·전자부품·커넥터를 넣은 결과에 따라 확대해야 한다. 확정 제작 치수가 아니다.

방사면 기준으로 마주 보는 면 사이가 150mm인 정팔각형을 예시로 잡으면 아포팀은 75mm, 한 변 길이는 `2*75*tan(22.5°) = 약 62.13mm`다. 패널 폭이 이보다 좁으면 패널 사이에는 개방 구간이 생긴다. 실제 기판 위치는 방사면보다 송신기 몸체 높이만큼 바깥쪽이다. 이미지의 외곽 300mm는 이 계산에서 자동으로 나오는 값이 아니며 프레임 단면과 장착 구조로 별도 확정해야 한다.

평면 패널의 모든 송신기는 해당 패널에 수직으로 방사한다. 중앙축에서 벗어난 두 열의 송신기를 개별적으로 중앙에 기울인 배치는 아니다. 시뮬레이션에도 각각의 실제 방향을 넣어야 한다.

## 전기 연결 제안

PC → FPGA → 8개 패널의 레지스터 → 드라이버 → 송신기로 연결한다. FPGA는 연속 40kHz 타이밍을 생성하고 PC는 목표 위상을 계산/전송한다.

FPGA 3.3V 신호를 5V 레지스터에 입력하는 경우 74HC595의 입력 임계값을 무조건 만족한다고 가정하지 않는다. 74HCT595 또는 명확한 레벨 변환 회로를 우선 검토한다. HCT595 2개에 각각 독립 데이터를 공급하는 안이라면 패널당 DATA 2줄, 공통 SHIFT/LATCH 클록, GND 및 필요한 전원 배선을 구성한다. 기존 256채널 펌웨어의 채널 매핑을 새 128채널 배열에 맞게 수정해야 한다.

구동 전원과 5V 논리 전원은 구분한다. 전원 분배부에서 각 패널로 공급하고 모든 GND는 연결한다. 패널마다 드라이버 근처의 로컬 디커플링과 벌크 커패시터를 둔다. FPGA 신호선은 전원과 함께 긴 무계획 직렬 연결로 이어붙이지 않고 클록 부하·배선 길이·접지 귀환 경로를 검토한다.

송신기의 상대 음향 극성을 조립 전에 확인하고 표시한다. 뒤집힌 채널은 배선을 수정하거나 위상에 180° 보정한다. 전원을 켤 때 출력이 의도하지 않게 켜지지 않도록 초기화와 출력 비활성 상태도 설계한다.

## 제작 파일로 넘어가기 전에 필요한 작업

채널 수 및 프레임 치수 확정 → 실물 송신기 풋프린트 확인 → 16채널 패널 회로도 → 기판 배치/배선 → ERC/DRC → 소규모 시제품 파형·발열·위상 검증 → 8패널 음장 및 부양 검증 순서로 진행한다.

이 문서는 새 구조의 설계 조건 정리이며, KiCad 원본이나 제조용 Gerber가 아니다. 기존 SonicSurface 동박 연결 검증을 새 구조의 전기/음향 검증 완료로 해석하지 않는다.
