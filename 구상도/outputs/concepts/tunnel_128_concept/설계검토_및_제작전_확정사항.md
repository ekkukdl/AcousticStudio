# 4분할 원통형 128채널 배열: 설계 검토 초안

이 문서는 사용자가 제시한 4개 CAD 이미지에 맞춘 설계 초안이다. 원통의 둘레를 4개 곡면 패널로 나누며 각 틈은 터널 길이 방향으로 이어진다. 길이 방향으로 원통을 4개 구간으로 자르는 구조가 아니다.

**현재 파일은 배치 검토용이다. 제작용 Gerber, 회로도, 확정 기구 도면은 포함하지 않는다. 실제 부양 성능과 새 회로의 동작은 아직 검증되지 않았다.**

## 1. 예시 치수와 배치

아직 사용자가 확정하지 않은 치수는 다음 예시를 사용했다. 단위는 mm이다.

| 항목 | 예시 값 | 의미 |
|---|---:|---|
| 음향 방사면 중심이 놓이는 원의 지름 | 100 | 지지대 내경이나 FPCB 지름과 구별해야 한다 |
| 배열 길이 | 160 | 커넥터 꼬리, 끝단 브래킷, 작업 여유는 별도 |
| 패널 사이 틈 | 8 | 방사면 반지름에서 측정하는 원호 길이; 직선 틈과 다름 |
| 송신기 외경 | 16 | V40AN16T를 후보로 사용 |
| 송신기 몸체 높이 | 12.5 | 핀 돌출 길이는 별도 |
| 패널 수 | 4 | 같은 구조를 90도씩 회전 |
| 패널당 개수 | 32 | 둘레 방향 4열 × 길이 방향 8개 |
| 전체 개수 | 128 | 송신기 1개마다 독립 출력 1개 |
| 길이 방향 중심 간격 | 20 | 16mm 몸체 사이에 명목상 4mm 여유 |
| 같은 패널의 둘레 방향 방사면 중심 직선거리 | 약 17.54 | 전체 몸체/프레임 간섭 검사를 대신하지 않음 |
| 송신기 후면 기준 반지름 | 62.5 | 방사면 반지름 50 + 몸체 높이 12.5 |
| 후면 원통을 이상적으로 펼친 패널 폭 | 약 88.17 | 실제 FPCB 외곽, 보강판, 평면 납땜 섬 설계에 따라 변경 |

방사면은 각 위치에서 원통의 중심축을 향한다. 각 방사면은 평평하므로, 실제 터널의 빈 공간은 완전한 원형 벽과 같지 않다. 방사면 모서리는 기준 원의 바깥쪽에 위치한다.

CSV의 원점은 앞쪽 끝면 중심이며 터널 축은 +Z이다. X/Y는 단면 좌표, normal은 안쪽을 향하는 단위벡터이다. 채널 번호는 `패널*32 + 둘레열*8 + 길이행`이다. 이는 새 설계를 위한 제안 번호이며 기존 FPGA 채널 번호와의 대응을 검증한 결과가 아니다.

## 2. 실제 제작 구조

권장 검토안은 **4개 기구 지지대 + 4개 FPCB 배열 + 외부 평면 드라이버 보드**이다.

- 기구 지지대에 송신기 몸체를 고정하고 하중을 받게 한다. 납땜 핀이 송신기의 무게와 조립 힘을 지탱하지 않도록 한다.
- FPCB의 송신기 핀 두 개가 들어가는 자리는 평평한 보강 영역으로 만든다. 보강 영역 사이만 휘도록 하고, 납땜 패드·관통홀·비아가 굽힘 구간에 들어가지 않게 설계한다.
- 부품을 평평하게 받치는 납땜 지그에서 조립한 뒤 지지대에 장착하는 공정을 검토한다. 이때도 보강 영역은 평평하게 유지해야 한다.
- 곡면 기준면과 평평한 부품 후면의 차이를 흡수하도록 FPCB에 연결부, 절개 또는 여유 길이를 설계한다. 단순 직사각형 FPCB를 휘어서 모든 송신기 핀에 끼울 수 있다고 가정하지 않는다.
- 드라이버 IC, 시프트 레지스터, 전원 커패시터는 외부 평면 PCB에 둔다. 방사면 앞에 부품이나 케이블이 나오지 않도록 한다.
- 일반 두꺼운 FR-4 기판을 이 반지름으로 강제로 휘는 방식은 채택하지 않는다. 대안은 각 패널을 여러 작은 평면 PCB로 구성하는 방식이다.

JLCPCB의 현재 공식 사양에는 FPCB와 보강판 옵션이 있지만 rigid-flex는 지원하지 않는다고 명시되어 있다. FPCB+보강판과 rigid-flex는 서로 다른 제작 방식이다. 이 업체를 최종 선정하거나 이 구조의 제조 가능성을 승인받은 상태는 아니다.

출처: [JLCPCB FPCB 제작 사양](https://jlcpcb.com/capabilities/flex-pcb-capabilities).

## 3. 전기 연결 제안

```text
PC의 위상 계산/전송
        ↓
FPGA: 연속 40kHz 출력 타이밍 생성
        ↓ 데이터·시프트 클록·래치 클록
외부 드라이버 PCB 4개, 각 32채널
        ↓ 패널마다 독립 출력 32개 + GND
곡면 FPCB 4개
        ↓
각 송신기: 한 핀은 해당 채널 OUT, 다른 핀은 GND
```

패널 하나를 담당하는 32채널 보드에는 74HCT595 4개와 TC4427A 듀얼 드라이버 16개를 사용하는 안을 검토한다. 전체로는 74HCT595 16개, 듀얼 드라이버 64개다. 두 드라이버 출력으로 송신기 하나를 구동하는 브리지 방식으로 바꾸면 필요한 IC 수가 달라진다.

FPGA는 3.3V 논리, HCT 레지스터는 5V 논리 전원으로 구성하는 안이다. TC4427A의 구동 전원은 별도로 공급하고 모든 보드의 GND를 공통으로 연결한다. 초기 구동 전압은 송신기 연속 구동 허용치와 실험 결과로 정한다. 송신기 데이터시트의 80Vpp impulse 수치를 연속 운전 정격으로 사용하지 않는다.

FPGA→드라이버 보드의 데이터는 보드마다 4줄, 전체 16줄을 제안한다. 클록은 모든 출력의 시간 기준을 맞추되 배선 길이와 부하에 맞게 버퍼와 직렬 저항을 검토한다. 기존 256채널 펌웨어를 그대로 써서 128채널이 정확히 대응한다고 가정하지 않는다.

드라이버→패널은 **2개의 20핀 연결부**를 예시로 검토할 수 있다. 각 연결부에 16개 독립 출력과 4개 GND를 배정하면 패널당 32개 출력과 8개 GND가 된다. 이는 핀 수 제안이며 커넥터 모델, 전류 정격, 케이블 길이, 핀 순서가 확정된 연결도가 아니다. 모든 송신기를 하나의 OUT에 병렬 연결하면 128개 독립 위상 제어가 불가능하다.

각 IC 가까이 0.1µF 디커플링을 두고 드라이버 전원에 추가 로컬 커패시터와 벌크 커패시터를 둔다. 최종 용량·배선 폭·커넥터 GND 수는 측정한 공급 전류, 출력 에지와 전원 리플에 맞춰 선정한다. 송신기 자체도 용량성 부하이며 전원 커패시터와 역할이 다르다.

회로 구조 근거: [원 논문](https://doi.org/10.3390/app11072981), [TC4427A 데이터시트](https://ww1.microchip.com/downloads/aemDocuments/documents/APID/ProductDocuments/DataSheets/TC4426A-TC4427A-TC4428A-1.5A-Dual-High-Speed-Power-MOSFET-Drivers-20001423.pdf). 새 원통 배열, HCT 사용 및 보드 분리는 별도 설계 제안이다.

## 4. 검증 상태와 제작 순서

기존 SonicSurface의 10mm·256채널 Gerber에서 출력 연결을 정적으로 추적했다. 이 결과는 새 16mm·128채널 원통 배열의 기구 간섭, 실제 전압, 발열, 위상 정확도나 부양 성공을 보장하지 않는다. 기존 FPGA 헤더의 물리 핀 대응도 아직 확정된 제작 연결도가 없다.

1. 방사면 기준 지름, 길이, 틈의 기준과 폭, 부양할 입자 조건, 기판 방식을 확정한다.
2. 실물 송신기의 핀 간격·핀 굵기·높이와 음향 극성을 확인하고 1열 기구 샘플로 체결과 납땜성을 검토한다.
3. 새 배열 좌표와 방향으로 음장, 압력 구배 및 목표 입자의 안정성을 시뮬레이션한다. 중앙 압력 크기만으로 부양을 판정하지 않는다.
4. 8채널 회로 시제품에서 전원 투입/종료 상태, 출력 파형, 위상, 전원 리플과 온도 상승을 측정한다.
5. 32채널 패널에서 기구 간섭, FPCB 굽힘 및 고정, 커넥터/케이블 영향을 검증한다.
6. 회로도 ERC, PCB DRC, 제조사 FPCB·보강판 DFM을 통과한 뒤 4패널 제작 파일을 낸다.

## 5. 이번 파일

- `tunnel_4panels_128_CONCEPT.scad`: OpenSCAD에서 치수를 바꾸는 배치 모델. 지지대는 구멍만 포함한 예시이며 고정 탭·나사·실제 보강판은 미설계다. FPCB 기준면은 옵션으로만 표시한다.
- `tunnel_layout_CONCEPT.png`: 128개 방사면 배치와 단면 미리보기.
- `transducer_positions_CONCEPT.csv`: 128개 방사면 중심 좌표와 안쪽 방향. BOM 가격표가 아니다.
- `parameters_CONCEPT.json`: 예시 치수와 계산값, 제한 사항.

OpenSCAD를 실행해 렌더링한 결과는 아직 없다. PNG는 동일 배치 수식으로 별도 생성하고 시각적으로 확인했다. 예시 좌표의 128개 고유 채널 번호와 단위 방향벡터를 확인했다. 전체 기구 충돌 검사와 음향 시뮬레이션은 아직 수행하지 않았다.
