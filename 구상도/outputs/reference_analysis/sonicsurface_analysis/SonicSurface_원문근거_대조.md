# SonicSurface 원문 근거 대조

확인일: 2026-10-02. 논문, 원저자의 조립 안내, 제조사 회로도와 공개 저장소를 대조했다.

## 1. 논문에 회로도 그림이 있다

논문 **Generating Airborne Ultrasonic Amplitude Patterns Using an Open Hardware Phased Array**, Applied Sciences 2021, 11(7), 2981의 **5페이지 Figure 2**가 8채널 구동 회로의 근거다.

- 595 한 개가 데이터 한 줄을 8개 출력으로 분배한다.
- 듀얼 드라이버 네 개가 송신기 여덟 개를 구동한다.
- 송신기의 다른 단자는 GND에 연결된다.
- 595 전원에는 **+5V**가 표시되어 있다.
- 같은 페이지의 설명은 시프트 클록 10.24MHz와 래치 클록 1.28MHz를 명시한다.

출처: [논문 DOI](https://doi.org/10.3390/app11072981), 로컬 논문의 3절 Hardware Design 및 Figure 2.

그림을 `paper_Figure2_circuit.png`로 추출했다. 이 그림은 회로 구조를 확인하는 출판 자료이며, 수정 가능한 KiCad/Altium 원본 회로도는 아니다. 특히 595의 핀 10과 13을 NC로 표시한 부분은 제조사 데이터시트의 /SRCLR와 /OE 명칭 및 실제 Gerber 연결과 다르다. 그림의 명칭을 그대로 새 회로도로 옮기지 않는다.

## 2. 전원에 대한 원저자 설명

[UpnaLab의 조립 안내](https://www.instructables.com/SonicSurface-Phased-array-for-Levitation-Mid-air-T/) Step 2는 5V 논리 전원과 구동 전원을 구분하고, 구동 전원을 양쪽 핀과 DC 잭에서 연결할 수 있다고 설명한다. Step 9는 구동 전원에서 5V로 강압해 논리부에 공급하는 방식을 언급한다. 이는 양쪽 잭이 같은 DRIVER_VDD 망이라는 동박 추적 결과와 일치한다.

따라서 **원저자의 설계 의도는 5V 논리 전원**이다. 다만 메인 PCB의 두 논리 분기를 실제 CoreEP4CE6 물리 헤더에 연결하는 정확한 위치는 별도 대조 대상이다. 문서의 5V 표기를 실물 측정 완료로 표현하지 않는다.

원저자 안내의 구동 전압 설명과 논문의 최대 전압을 새 부품의 연속 구동 허용값으로 전용하지 않는다. 특히 TC4427A와 MIC4127은 같은 전압 정격이 아니다.

## 3. 트랜스듀서는 같은 면에 장착한다

논문 **3페이지, 3절 첫 문단**은 송신기를 PCB 한쪽 면에, FPGA·시프트 레지스터·드라이버·커패시터를 반대 면에 장착한다고 설명한다.

논문 **6페이지 Figure 3**은 256개 송신기가 모두 같은 면에 배치된 완성 사진과 전자부품이 있는 반대 면 사진을 보여 준다. 그림을 `paper_Figure3_assembly.png`로 추출했다.

따라서 **8개만 반대 방향으로 송신하도록 설계한 배열이라는 해석을 뒷받침하는 근거는 없다.** 좌표표의 Top 248개 / Bottom 8개 표기는 실제 조립 설명과 불일치한다. 출력 메타데이터 또는 CAD 배치 속성 문제일 가능성이 있다는 것은 추론이며, 그 원인 자체를 원저자가 확인한 것은 아니다. 자동 실장 자료를 만들 때에는 전체 송신기의 물리적 장착 방향을 동일하게 확인해야 한다.

이 문제는 송신기의 음향 극성과 별개다. 같은 면에 장착해도 음향 극성은 별도로 검사·보정한다.

## 4. 16mm 모델도 논문에 등장한다

논문 **5페이지 하단 및 6페이지 Figure 4**에는 16mm 송신기와 관통형 부품을 사용하는 별도 평면 배열 모델이 소개되어 있다. 따라서 16mm 송신기 사용 자체는 해당 연구에서도 다뤄졌다.

그러나 현재 폴더는 **10mm SMD 배열용**이다. Figure 4의 존재가 이 Gerber에 16mm 부품을 직접 장착할 수 있다는 근거는 아니다. 128채널 원통형 배치도 이 논문의 평면 모델과 별도로 설계해야 한다.

## 5. FPGA 핀과 수정용 CAD 원본

제조사 원문:

- [CoreEP4CE6 회로도](https://files.waveshare.com/upload/5/5b/CoreEP4CE6-Schematic.pdf): P1/P2 연결, 3.3V·5V 및 전원 회로.
- [CoreEP4CE6 핀 설정 자료](https://files.waveshare.com/upload/0/01/EP4CE6-pin-conf.txt): 칩 핀과 H_LEFT/H_Right 번호의 관계.
- [원저자의 FPGA primary 설정](https://github.com/upnalab/SonicSurface/blob/main/Firmware/FPGA%20primary/QuadrupleBuffer.qsf): DATA[0..31], SHIFT_CLOCK_1/2, LATCH_CLOCK_1/2 및 MISC_A~F.

이 자료에서 칩 핀 할당은 확인할 수 있다. 다만 메인 PCB 소켓의 좌표 인덱스가 위 문서의 물리 헤더 번호와 같다고 가정하지 않는다. 두 제조사 자료는 오른쪽 헤더의 홀짝 핀 표기에서도 차이가 있으므로 실제 커넥터 방향과 기준면을 확인해야 한다.

[PCB 원본 요청 이슈](https://github.com/upnalab/SonicSurface/issues/1#issuecomment-5329752779)에서 원저자 Asier Marzo는 회로 세부사항을 논문에서 볼 수 있다고 답했다. 또한 ESP32를 사용하는 모듈식 새 버전을 개발 중이라고 설명했다. 이 답변에는 현재 버전의 수정용 PCB CAD 파일이 첨부되어 있지 않다. 미래 버전의 공개 완료를 의미하지도 않는다.

## 6. 문서로 확인한 것과 제조 파일에서 확인한 것

| 항목 | 근거 | 상태 |
|---|---|---|
| 8채널당 595 1개·듀얼 드라이버 4개 | 논문 Figure 2, 실제 동박 | 두 자료가 일치 |
| 설계 의도의 논리 전원 5V | 논문 Figure 1/2 및 원저자 안내 | 문서로 확인 |
| 256개 같은 면에 장착 | 논문 3절 및 Figure 3 | 문서·사진으로 확인 |
| 8개만 Bottom 표기의 원인 | 해당 좌표표와 논문 비교 | 불일치는 확인, 원인은 미확정 |
| 커패시터 168개 | 해당 버전 Main.CSV 및 좌표표 | 제조 파일에서 확인. 간략 공개 BOM은 160개 |
| 추가 커패시터 8개가 구동 전원에 연결 | Main.GTL/GBL 동박 복원 | 정적 연결 추적 결과 |
| 모든 256채널의 연결 일치 | 동박 복원 및 패드 대조 | 정적 검증 결과 |
| FPGA와 메인 PCB의 정확한 물리 핀 대응 | 코어보드 문서와 메인 PCB를 추가 대조해야 함 | 제작용 확정 연결표는 아직 없음 |
| 실제 소비전력·발열·파형·부양 | 실물 계측 필요 | 미측정 |

기존 `SonicSurface_동박연결_검증.md`와 함께 사용한다. 문헌 대조가 실물 검증을 대신하지 않으며, 실제로 확보한 문서·파일과 추론을 위와 같이 구분했다.
