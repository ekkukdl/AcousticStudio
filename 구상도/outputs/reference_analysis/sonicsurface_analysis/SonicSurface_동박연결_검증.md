# SonicSurface 1.2 동박 연결 검증

검증일: 2026-10-02. 대상: Main.GTL, Main.GBL, Main.GTS, Main.TXT, Main.CSV, Pick Place for Main.txt 및 FPGA primary 소스.

후속 [원문 근거 대조](SonicSurface_원문근거_대조.md)에서 논문 Figure 2의 +5V 표기와 Figure 3의 동일 면 송신기 장착을 확인했다. 설계 의도의 논리 전압과 장착 방향은 문서로 확인되었으며, 실제 커넥터의 물리 핀 대응 및 실물 계측은 별도다.

## 검증 결과

상·하층 Gerber의 동박, clear 영역과 패드 형상을 복원하고, 도금 관통홀 좌표를 통해 두 층의 연결을 합쳤다. IC의 패드 위치는 부품 좌표표와 솔더마스크에 대조했다. 아래 결과는 **제조 파일에서 추적한 정적 연결 검증**이며 완제품 통전 시험이나 원본 CAD의 ERC/DRC는 아니다.

| 확인 항목 | 결과 |
|---|---|
| 부품 592개 패드의 동박 대응 | 대응하지 못한 패드 0개 |
| 시프트 레지스터 → 드라이버 입력 | **256/256 연결** |
| 드라이버 출력 → 송신기 단자 | **256/256 연결** |
| 송신기의 다른 단자 → 공통 GND | **256/256 연결** |
| 드라이버 GND 핀 | 128개 모두 공통 GND |
| 드라이버 전원 핀 | 128개 모두 동일 DRIVER_VDD 망 |
| 드라이버 핀 1·8 | 각각 128개 모두 다른 부품과 연결되지 않은 NC 패드 |
| 595의 출력 활성 /OE, 핀 13 | 32개 모두 GND에 고정 |
| 595의 리셋 /SRCLR, 핀 10 | 32개 모두 해당 논리 전원에 고정 |
| 논리 전원 | PCB 내부에서 서로 분리된 **2개 망**, 각각 24개와 8개의 595에 공급 |
| 드라이버 전원과 논리 전원, GND | 동박 추적상 서로 구분됨. 이 사이의 직접 단락은 찾지 않음 |
| 시프트 클록 / 래치 클록 | 각각 2개 망. 각 망은 595 16개의 해당 핀에 연결 |
| 드릴 좌표 | 1,505개, 드릴 보고서와 일치 |

32개 반복 묶음 각각에서 595 출력 8개가 정확히 드라이버 4개로 연결됨을 확인했다. 256개의 595 출력 망과 256개의 드라이버 출력 망은 각각 서로 다른 망이다. 595 직렬 입력도 32개의 서로 다른 망이다.

송신기 두 단자 구멍 사이의 거리는 256개 모두 **약 5.0mm**다. 외경뿐 아니라 새 16mm 부품의 핀 간격도 기존 풋프린트와 별도로 대조해야 한다.

## 실제 핀 연결

드라이버는 TC4427A SOIC/PDIP 핀 배치와 일치하는 연결 구조다. 실제 실장할 품번의 반전 여부, 정격, 패키지는 별도로 일치시켜야 한다.

| 드라이버 핀 | 기능 | 동박에서 확인한 연결 |
|---:|---|---|
| 1 | NC | 다른 부품 연결 없음 |
| 2 | IN A | 595의 출력 하나 |
| 3 | GND | 공통 GND |
| 4 | IN B | 595의 다른 출력 하나 |
| 5 | OUT B | 송신기 단자 하나 |
| 6 | VDD | DRIVER_VDD |
| 7 | OUT A | 다른 송신기의 단자 하나 |
| 8 | NC | 다른 부품 연결 없음 |

595의 출력 핀은 QA~QH = 15, 1, 2, 3, 4, 5, 6, 7이다. GND는 8, 전원은 16, 시프트 클록은 11, 래치 클록은 12, 직렬 데이터 입력은 14다.

```text
595 출력 → 드라이버 IN A(2) → OUT A(7) → 송신기 → GND
595 출력 → 드라이버 IN B(4) → OUT B(5) → 송신기 → GND
드라이버: VDD(6), GND(3)
```

이는 양쪽 단자를 반대 위상으로 구동하는 브리지 방식이 아니라 한쪽 출력과 GND 사이의 단일 출력 구동이다. 외부 MOSFET을 추가해야 동작하는 구조로 해석하지 않는다.

## 커패시터와 DC 잭

- 0.1µF 커패시터 **32개**: 논리 전원과 GND 사이.
- 0.1µF 커패시터 **136개**: 드라이버 전원과 GND 사이.
- 따라서 기존 상세 BOM의 추가 8개도 드라이버 전원 바이패스에 연결된다.
- J1, J4의 드라이버 전원 단자는 **같은 망**에 연결된다. 잭 2개를 독립된 전원으로 해석하지 않는다.
- 드라이버 전원 단자 좌표: J1 **(176.45609, 21.24710)mm**, J4 **(8.63600, 21.33600)mm**.
- J1의 나머지 두 접점과 J4의 나머지 두 접점은 GND 망에 연결된다. 전원 잭의 스위치 접점 역할은 정확한 실장 잭의 데이터시트와 함께 확인한다.

## 좌표로 확인한 커넥터 연결

좌표는 Main.GM1과 동일한 좌하단 원점, top에서 보는 방향이다. **아래 위치를 실제 보드의 커넥터 번호와 혼동하지 않는다.** 좌표표에 기록된 헤더 Pad X/Y가 제조사 코어보드의 물리 핀 번호와 일치함을 확정하지 못했으므로 커넥터 번호를 제작용으로 확정하지 않았다.

| 연결 | 확인한 위치·연결 |
|---|---|
| J2 논리 전원 분기 | (93.75394, 42.92600)mm → 595 8개의 VCC |
| J3 논리 전원 분기 | (93.72600, 83.56600)mm → 595 24개의 VCC |
| J2 시프트 클록 | y=42.92600mm, x=83.59394/86.13394/88.67394/91.21394mm의 네 패드가 같은 망. 595 16개의 핀 11에 연결 |
| J2 래치 클록 | 동일한 네 x 좌표, y=40.38600mm. 595 16개의 핀 12에 연결 |
| J3 시프트 클록 | y=83.56600mm, x=83.56600/86.10600/88.64600/91.18600mm의 네 패드가 같은 망. 595 16개의 핀 11에 연결 |
| J3 래치 클록 | 동일한 네 x 좌표, y=86.10600mm. 595 16개의 핀 12에 연결 |

전체 패드의 좌표와 동박 연결은 `pad_connectivity.csv`에 기록했다. IC 핀 번호는 부품 좌표와 데이터시트에 대조한 번호이며, 커넥터·전원 잭의 숫자는 **좌표를 구분하는 인덱스**다. CSV의 Copper net 숫자는 이 분석에서 생성한 식별자이며 원본 CAD의 넷 이름이 아니다.

## 기존 동작을 그대로 복제할 때의 의미

1. **595 /OE는 FPGA가 제어하는 별도 신호가 아니다.** 원본은 GND 고정이다. FPGA 시작 전 출력이 항상 0임을 이 연결만으로 보장하지 않는다. 새 128채널 설계에서 출력 차단을 원하면 /OE 제어와 드라이버 입력 풀다운 등을 별도 설계한다.
2. **595 직렬 데이터 입력은 FPGA 커넥터로 연결된다.** 여러 595를 한 줄로 모두 직렬 연결한 회로로 단순화하면 원본과 다른 데이터 전송 구조가 된다.
3. 시프트·래치 각각 두 망에 대해 FPGA primary QSF는 SHIFT_CLOCK_1/2를 칩 PIN_28/85, LATCH_CLOCK_1/2를 PIN_30/84에 할당한다. **이 칩 번호가 곧 J2/J3의 핀 번호라는 뜻은 아니다.**
4. HC595의 실제 공급 전압을 Gerber만으로 알아낼 수는 없다. 제조사 코어보드에는 3.3V·5V가 모두 있지만, 위 두 논리 분기와 물리 핀의 대응은 남은 확인 항목이다. 새 예산의 5V HCT595 구성은 원본 전압을 확인한 결과가 아니라 별도 설계 제안이다.

## 검증의 범위와 남은 항목

확인한 것은 동박 경로와 부품 패드 연결이다. **256채널 모두 연결 구조가 일관되지만, 이 결과만으로 제조·전원 인가를 승인할 수 있다는 의미는 아니다.** 다음은 아직 검증하지 않았다.

- 실제 CoreEP4CE6의 물리 헤더 방향과 J2/J3의 정확한 핀 번호 대응, 두 논리 분기의 실제 전압.
- 부품 좌표표의 Bottom 송신기 8개에 대한 실제 조립 의도 및 음향 극성.
- 원본 CAD 넷리스트와의 일치, 제조 규칙에 따른 최소 간격/드릴/실장 DRC 및 절연 내압.
- 10.24MHz 신호 품질, 부하 구동 전류, 발열, 전원 리플, 위상 정확도, 실제 부양 성능.

연결 복원은 도금 관통홀을 통해 위·아래 동박이 연결된다고 가정했다. 그 근거는 Main.TXT의 `TYPE=PLATED`다. 곡선이 없는 동박층의 선·플래시·영역과 polarity를 처리했으며 원형 패드는 다각형으로 근사했다. 원본 CAD의 ERC/DRC를 실행한 것은 아니다.
