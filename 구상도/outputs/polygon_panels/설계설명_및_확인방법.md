# 6면·8면 초음파 부양 패널 PCB P0

작성일: 2026-10-04. 16mm 송신기, 기존 128채널 이내 조건, 8채널 회로 반복 구조를 기준으로 만든 **시제품 설계**다. 각 폴더에는 수정 가능한 KiCad 회로도·배선 완료 PCB·프로젝트·로컬 부품 라이브러리가 있다. KiCad 10.0.6으로 불러오고 검사했다.

## 1. 개수 선정의 의미

**음향적으로 최적인 개수는 아직 확정할 수 없다.** 부양할 물체의 크기·밀도, 실제 구동 전압, 목표 이동 범위, 터널 치수가 확정되지 않았다. 이번에는 제작과 제어의 표준화를 우선한 추천 후보를 선정했다. 사용자 응답 전까지 기존 128채널 이내 조건과 예시 치수를 유지했다.

| 항목 | 6면 후보 | 8면 후보 |
|---|---:|---:|
| 패널 수 | 6 | 8 |
| 패널당 송신기 | 16 = 2열 × 8행 | 16 = 2열 × 8행 |
| 전체 송신기 / 독립 출력 | **96** | **128** |
| 마주 보는 방사면의 평면 간 거리 | 150mm 가정 | 150mm 가정 |
| 길이 방향 중심 간격 | 20mm | 20mm |
| 폭 방향 중심 간격 | 18mm | 18mm |
| 송신기 부분 길이 / 폭 | 156mm / 34mm | 156mm / 34mm |
| PCB 한 장 크기 | **60 × 180mm** | **48 × 180mm** |
| PCB 동박 층수 / 두께 | 2층 / 1.6mm | 2층 / 1.6mm |
| 레지스터 / 듀얼 드라이버, 패널당 | 2 / 8 | 2 / 8 |
| 레지스터 / 듀얼 드라이버, 전체 | 12 / 48 | 16 / 64 |

선정 이유는 같은 16채널 회로를 반복하면서, 행 수·송신기 간격·예시 터널 크기를 동일하게 두어 6면과 8면의 차이를 비교할 수 있기 때문이다. 6면 기판은 넓은 고정 여유를 두었고, 8면 기판은 패널 폭을 줄였다. 고정 구조를 바꾸면 공통 크기의 기판으로 통일할 수도 있다. 서로 다른 기판 폭이 음향 성능을 개선한다고 주장하지 않는다.

대안으로 6면 120개(패널당 2×10), 6면 126개(3×7), 6면 144개(3×8), 8면 192개(3×8)도 가능하다. 120개는 배열 길이가 증가하고, 126개는 패널당 24출력 회로 중 21개만 쓰는 등의 구성이 필요하다. 144개와 192개는 기존 128채널 조건을 넘는다. 이 대안들을 음향적으로 열등하다고 판정한 것이 아니다. **최대 부양력만을 목표로 하면 추천 개수와 형상이 달라질 수 있다.**

16mm 후보 송신기의 지향각은 약 60°(전각, -6dB 기준)다. 이번 평면 배열에서 중앙 높이 90mm로 향하는 끝 행의 방향 차이는 약 43°다. 끝 행의 소리가 중앙에 도달하지 않는다는 뜻은 아니지만, 중앙을 향해 개별적으로 기울인 배열보다 감쇠가 클 수 있다. 긴 배열은 길이 방향 이동을 검토하기 위한 형상이다. 중앙 한 점의 힘을 최대화하는 배열과 동일하지 않다.

## 2. 기존 SonicSurface에서 참고한 것

원본 위치:

`simulations/SonicSurface/Electronics/16x16 10mm transducers SMD PCB Gerbers/SonicSurface1.2_2Layers_183x169/Project Outputs for SonicSurface/`

원본에는 Gerber·드릴·부품 좌표가 있으며, 수정 가능한 KiCad/Altium 회로도 원본은 발견되지 않았다. 이번 회로도는 기존 제조 파일의 연결 추적, 논문의 Figure 2, 부품 데이터시트를 대조해 **새로 작성한 회로도**다. 원본 기판을 단순히 확대하거나 축소한 파일이 아니다.

원본에서 유지한 구조:

- 시프트 레지스터 출력 8개 → 듀얼 드라이버 4개 → 송신기 8개.
- 송신기 한 핀은 독립 드라이버 OUT, 다른 핀은 GND. 브리지 구동이 아니다.
- 논리 전원과 드라이버 전원을 구분하고 GND는 공통으로 연결.
- 레지스터마다 독립 직렬 DATA를 공급하고 SHIFT/LATCH 타이밍은 공유.

새 설계에서 바꾼 것:

- 10mm 송신기용 약 5mm 핀 간격을 16mm V40AN16T용 **10mm 핀 간격**으로 변경.
- 5V에서 사용하는 레지스터를 **SN74HCT595D**로 지정. 3.3V FPGA 입력을 받는 조건에서 74HC595의 입력 임계값을 무조건 만족한다고 가정하지 않음.
- 드라이버를 비반전 **TC4427ACOA, SOIC-8**로 지정. 핀 번호를 제조사 자료와 대조.
- 원본의 /OE GND 고정 대신 출력 활성화 제어 **ARM** 추가. Q1 MMBT3904가 3.3V ARM으로 /OE를 낮추며, 기본 상태는 비활성으로 설계.
- 레지스터가 비활성일 때 드라이버 입력이 뜨지 않도록 채널마다 10kΩ 풀다운 추가.
- 각 드라이버 가까이 100nF 및 1µF, 패널 전원에 벌크 커패시터 추가.
- 송신기 번호와 IC 번호를 기판에 표시. 전체 부품 번호와 외형은 F.Fab/B.Fab에 포함.

근거: [논문](https://doi.org/10.3390/app11072981), [원본 공개 저장소](https://github.com/upnalab/SonicSurface), [TI SN74HCT595](https://www.ti.com/lit/ds/symlink/sn74hct595.pdf), [Microchip TC4427A](https://ww1.microchip.com/downloads/aemDocuments/documents/APID/ProductDocuments/DataSheets/TC4426A-TC4427A-TC4428A-1.5A-Dual-High-Speed-Power-MOSFET-Drivers-20001423.pdf).

기존 분석 근거는 `outputs/sonicsurface_analysis/SonicSurface_동박연결_검증.md`와 `SonicSurface_원문근거_대조.md`에 보관되어 있다.

## 3. 패널 연결

**아래 핀 번호는 새 패널 PCB의 커넥터 번호다. Waveshare FPGA 보드의 헤더 번호와 동일하지 않다.**

| J1 핀 | 기능 | 연결 방향 |
|---:|---|---|
| 1 | GND | FPGA와 공통 접지 |
| 2 | +5V | 패널 논리 전원 |
| 3 | DATA_A | FPGA → U1, 로컬 채널 0~7 |
| 4 | GND | 신호 귀환 |
| 5 | DATA_B | FPGA → U2, 로컬 채널 8~15 |
| 6 | GND | 신호 귀환 |
| 7 | SHIFT_PIN | FPGA 시프트 클록 → 33Ω → SHIFT |
| 8 | LATCH_PIN | FPGA 래치 클록 → 33Ω → LATCH |
| 9 | ARM | FPGA 3.3V HIGH로 출력 활성화, LOW로 비활성화 |
| 10 | GND | 신호 귀환 |

| J2 핀 | 기능 |
|---:|---|
| 1 | DRV_VDD, 드라이버 전원 |
| 2 | GND |
| 3 | +5V, 논리 전원 |

J1의 +5V와 J2의 +5V는 같은 망이다. 같은 5V 전원을 분배하며, 서로 독립된 전원을 임의로 병렬 연결하지 않는다. +5V를 FPGA의 3.3V GPIO에 연결하는 방식이 아니다. 각 패널의 전원은 외부 분배부에서 공급한다. 패널 자체에는 12→5V 변환기나 FPGA 전원 회로가 없다.

DRV_VDD의 실제 운전값은 송신기의 연속 구동 허용치와 시제품 계측으로 정해야 한다. TC4427A의 동작 전압 범위는 4.5~18V다. V40AN16T의 80Vpp impulse 수치를 연속 운전 전압으로 사용하지 않는다. 두 부품의 정격을 함께 만족해야 한다.

각 송신기의 상대 음향 극성을 측정하고 보정해야 한다. PCB의 T 핀 1은 해당 OUT, 핀 2는 GND라는 배선 정의이며 제조사 표기가 실제 음향 위상을 보장한다는 뜻이 아니다.

## 4. 채널과 FPGA 통합

패널은 P0부터 번호를 매긴다. 로컬 송신기는 T1~T16이고, 로컬 채널은 0~15다. 배열 JSON의 전역 채널은 `패널번호*16 + 로컬채널`이다. 첫 4행은 U1, 뒤 4행은 U2가 담당한다.

각 레지스터의 로컬 출력 0~7은 실제 핀 15, 1, 2, 3, 4, 5, 6, 7에 대응한다. 전송 비트 순서는 FPGA 소스와 실제 파형을 함께 확인해야 하며, JSON의 순서만으로 기존 펌웨어와 호환됨을 판정하지 않는다.

기존 `Firmware/FPGA primary/QuadrupleBuffer.qsf`에는 DATA[0..31]과 SHIFT_CLOCK_1/2, LATCH_CLOCK_1/2의 칩 핀 할당이 있다. 새 96채널에는 DATA 12줄, 128채널에는 16줄이 필요하다. 실제 코어 보드 헤더 위치와 ARM GPIO 할당은 아직 확정하지 않았다. **이 패키지는 FPGA 어댑터 보드나 수정·컴파일한 FPGA 펌웨어를 포함하지 않는다.**

패널마다 짧은 신호 케이블을 사용하고, 클록 분배는 6면 3+3 또는 8면 4+4처럼 나누는 안을 검토할 수 있다. 버퍼, 직렬 저항, 케이블 길이와 분기 방식은 파형 측정으로 확정한다. PCB의 33Ω만으로 긴 케이블의 신호 품질을 보장하지 않는다.

시제품에서는 ARM을 LOW로 유지한 상태에서 공급 전압과 레지스터 데이터를 안정화한 뒤 활성화한다. 전원 순서 전체와 비정상 상태에서의 출력 차단은 실제 계측이 필요하다.

## 5. KiCad에서 확인하는 방법

1. KiCad를 실행하고 해당 폴더의 `panel_6faces_16ch.kicad_pro` 또는 `panel_8faces_16ch.kicad_pro`를 연다. 이 PC에는 KiCad 10.0.6을 설치했다.
2. **회로도 편집기**에서 `.kicad_sch`를 연다. 같은 이름의 넷 라벨은 선을 길게 그리지 않아도 전기적으로 연결되어 있다. 예를 들어 U1의 IN00과 U3의 IN00은 같은 망이며 U3의 OUT00은 T1로 간다.
3. **PCB 편집기**에서 `.kicad_pcb`를 연다. F.Cu/B.Cu는 배선, F.Silkscreen/B.Silkscreen은 인쇄, F.Fab/B.Fab은 전체 부품 번호와 조립 외형이다. T는 안쪽 면, U·R·C·Q·커넥터는 바깥쪽 면이다.
4. 부품 위에서 `E`를 눌러 값, 풋프린트와 패드 넷을 확인한다. 넷 강조 기능으로 `OUT00`을 선택하면 드라이버와 송신기 사이 연결을 추적할 수 있다. `/`는 회로도 로컬 넷 이름에 붙는 경로 표기다.
5. PCB 편집기에서 **보기 → 3D 뷰어**, 또는 `Alt+3`을 누른다. 송신기는 외경 16mm·높이 12.5mm의 단순 외형 모델이다. 메시·전극·실제 내부 형상을 재현한 정밀 모델은 아니다.
6. **검사 → 디자인 규칙 검사(DRC)**를 실행하고, 가능하면 회로도와 일치 여부도 검사한다. 회로도 편집기에서도 **검사 → 전기 규칙 검사(ERC)**를 실행한다. 수정 후에는 접지 영역을 다시 채우고 검사한다.
7. Gerber 뷰어에서 `gerbers_P0`의 동박·마스크·외곽과 `.drl`을 함께 연다. 기판 외곽, 송신기 10mm 핀 간격, 고정홀, 부품 패드를 확인한다.

프로그램 없이 먼저 보려면 `PCB_6_8_comparison.png`, 각 폴더의 `pcb_top.png`, `pcb_bottom.png`, `schematic_preview.png`를 연다. 회로도 SVG와 동박/조립 SVG는 브라우저에서 확대해서 볼 수 있다.

`assembly_6faces_CONCEPT.scad`와 `assembly_8faces_CONCEPT.scad`는 OpenSCAD용 조립 개념 모델이다. 프레임에는 최종 고정 탭, 전자부품·케이블 회피 형상과 나사 체결 상세가 들어 있지 않다. OpenSCAD 자체를 설치하거나 이 모델을 렌더링한 상태는 아니다. 조립 PNG는 동일한 배열 좌표로 생성했다.

## 6. 완료한 검사

| 검사 | 6면 패널 | 8면 패널 |
|---|---:|---:|
| KiCad ERC 위반 | 0 | 0 |
| KiCad DRC 위반 | 0 | 0 |
| 미연결 항목 | 0 | 0 |
| 회로도와 PCB 불일치 | 0 | 0 |
| 설계 명세·회로도 넷리스트·PCB가 일치하는 연결 패드 | 216 | 216 |
| 접지 동박 | 앞·뒤 채움 | 앞·뒤 채움 |
| 최소 실제 배선 폭 | 0.1874mm | 0.1874mm |

일반 신호의 목표 폭은 0.25mm, 드라이버 전원은 0.8mm, 논리 전원/접지 배선은 0.4mm다. 일부 패드 주변의 짧은 신호 탈출 구간은 약 0.1874mm로 줄어든다. 최소 제조 규칙은 0.15mm, 일반 간격 0.20mm, 드라이버 전원 간격 0.25mm로 설정했다. 위반을 제외 처리해 0으로 만든 것이 아니다. 기존 회로 구조를 그대로 확대/축소하지 않고 새로 배선했으며 실제 배선과 회로도 일치 검사를 수행했다.

GND 동박은 패드에 직접 연결한다. 접지 납땜 패드는 가열이 더 필요할 수 있으므로 적절한 납땜 공정과 지그를 검토한다. 송신기 핀의 뒤쪽 돌출 길이도 전자부품과 간섭하지 않도록 실물에서 확인하고 정리해야 한다.

재검사는 폴더에서 다음 명령으로 할 수 있다:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\verify_designs.ps1
```

스크립트는 KiCad CLI로 두 설계의 ERC·DRC·회로도 일치를 검사하고 `recheck` 폴더에 보고서를 저장한다. 전역 실행 정책을 바꾸는 명령이 아니다.

## 7. 제작 전에 남은 확인

Gerber/드릴 파일은 **P0 시제품 후보 출력물**이며, 실물 동작 검증을 마친 제작 승인본은 아니다. 구매할 송신기의 핀 굵기·간격·음향 극성, 정확한 부품 패키지, 커넥터 정격과 방향, 프레임 고정 간섭을 확인해야 한다.

한 패널 시제품에서 출력 파형, 위상, 전원 리플, 온도 상승과 ARM 동작을 확인한 뒤 전체 패널로 확장한다. 부양력은 물체의 중량을 버틸 수 있는 수직 힘과 3축 복원력을 함께 검증해야 한다. 터널을 세우거나 눕힌 경우의 중력 방향도 모델에 반영한다. 배열 좌표 JSON은 이를 위한 입력 자료이며, 음장 계산 결과가 아니다.

PCB ERC/DRC 통과는 부양 성공, 연속 구동 안전 전압, FPGA 통합 완료 또는 제조사의 DFM 승인을 의미하지 않는다.
