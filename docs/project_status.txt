- 헤더는 고정 높이로 정리하고, 오른쪽 각 작업 탭에 독립 스크롤을 적용해 탭 선택부가 스크롤에 가려지지 않도록 보완했다.
- 좁은 패널에서 가로 스크롤을 만들던 7열 좌표 입력을 두 개의 간결한 정보 행(위치/회전)으로 재구성하고, 그룹 제목은 불필요한 번호·영문을 제거해 짧게 정리했다.
- 시각 테마는 진한 남색 일변도에서 밝은 중성 배경과 단일 파란 강조색으로 바꿨다. 콤보박스 목록, 탭, 입력창, 버튼, 상태 표시는 같은 색 체계를 따르며, 삭제 동작만 경고색을 유지한다.
- 메뉴·주요 버튼·상태 메시지의 영문 혼용을 정리하고, 숫자 입력칸의 증감 화살표를 숨겨 시각 잡음을 줄였다. 궤적 삭제 버튼은 옅은 경고색 테두리로 조정해 주 동작 버튼과 경쟁하지 않게 했다.
- 상단 연산 모드는 긴 CPU/GPU 장치명 대신 짧은 엔진명으로 표시하고 전체 장치 정보는 도움말에 보존해 잘림을 방지했다. 작업 탭은 패널 폭을 균등하게 채우는 세그먼트형 탭으로 바꿨다.
- 사용자 피드백에 따라 상단 프로젝트 안내 패널은 제거하고, 포트 새로고침은 텍스트 대신 회전 화살표 아이콘으로 변경했다. 연산 모드의 상세 장치명과 상태 표시 기능은 그대로 복원했으며, 강조색은 부드러운 블루그레이로 조정했다.
- 선택형 콤보박스는 옅은 블루그레이 바탕과 분리된 드롭다운 영역으로, 수치·텍스트 입력은 흰색 바탕으로 표시해 두 조작 유형을 구분했다.
- 콤보박스의 드롭다운 영역에 역삼각형 표식을 추가했다. 메인 화면의 보드 연결줄은 상단 `보드` 메뉴의 전용 설정 창으로 옮겨, 긴 장치명에 의한 상단 글자 잘림을 해소했다.
- 보드 메뉴 구성은 사용자 피드백으로 조정했다. 보드 프로파일 선택만 상단 `보드` 메뉴로 유지하고, 포트·새로고침·통신속도·연결·위상 전송·연산 모드는 메인 상단바로 복원했다.
- 콤보박스의 드롭다운 표식은 Qt 스타일만으로 막대처럼 렌더링되던 문제를 해결하기 위해 SVG 꺾쇠형 역삼각형 아이콘으로 교체했다.
- 배열·제어점·위상 계산·음압 단면·k-Wave·궤적 및 하드웨어 통신의 기존 위젯과 연결 로직은 유지했다. 이번 단계는 정보 구조와 시각 체계 변경이며, 계산식·프레임 프로토콜은 변경하지 않았다.

- **PyVista 기반 3D 실시간 렌더링 뷰어 완성**: 트랜스듀서 배열 및 제어점을 직관적으로 조작할 수 있는 환경 구축. 배열 초기화(Clear All) 시 30초 이상 걸리던 랙 현상을 0.4초 이하로 최적화 완료.
- **다중 가속 연산 엔진 통합**: Numba(CPU), C++ DLL, Taichi(GPU), PyTorch(GPU) 등 하드웨어 가속 다중 연산 모드를 지원하며, 사용자 환경에 맞춰 최적의 엔진을 자동 선택.
- **오프라인 궤적(Trajectory) 및 시뮬레이션 시스템**: 객체를 시작점에서 목표점까지 옮기는 3D 궤적(Linear Transport) 애니메이션 생성, 미디어 컨트롤러, 궤적 리스트 관리 기능 완비.
- **하드웨어 제어 (보드 연동)**: 시뮬레이션 위상 데이터를 Serial Port를 통해 실제 보드로 실시간 전송 (SonicSurface 기반 32단계 위상 분할 패킷 적용).
- **UI/UX 편의성 고도화**:
  - 상태 표시줄에 실시간 CPU/GPU 리소스 모니터링 메뉴 추가.

  - QSettings를 연동하여 CPU/GPU 모니터링 옵션 상태(On/Off) 영구 저장 유지.

  - 알림/경고 다이얼로그(show_silent_msg)의 최소 너비를 기존 350px에서 420px로 확장하여, 단어 하나만 다음 줄로 밀려나던 고립 줄바꿈 현상 원천 해결.

- **궤적 물리 안정성 진단 고도화 (이모지 배제 및 공학 4단계 등급화)**:
  - 이모지를 완전히 배제하고 신뢰성 높은 공학적 4단계 등급 체계 구축: 최적(85%+), 안정(60~84%), 주의(40~59%), 위험(<40%).
  - 궤적 리스트 명칭 간소화: '[선형]: ... [안정 65%]', '[일반 등속]' 형태로 깔끔하게 표기.
  - 우측 패널에 '물리 안정성 진단 미니 요약 카드'를 신설하여 궤적 선택 시 실시간 등급, 평균/최저 안정도, 공학 가이드 코멘트(적응형 감속 적용 여부, 딜레이 권장 등)를 한눈에 제공.
- **levitate 물리 연산 기반 선형 이송 궤적 최적화 구현**:
  - mm ↔ m 물리 단위계 정합화(1,000배 단위 오차 원천 해소).
  - PhaseEngine 내에 optimize_trajectory_physical 모듈을 구축하여 경로상 각 웨이포인트에서의 3차원 음향 복원력 스티프니스(Radiation Force Stiffness) 및 트랩 강도를 정밀 연산.
  - 트랩 강도 취약 구간에서의 적응형 지연시간(Adaptive Delay) 동적 배분 및 급가속/급감속 관성 이탈 방지를 위한 S-curve(Cosine ramp) 가감속 스무딩 적용.
  - 궤적 리스트 및 하단 상태 표시줄에 실시간 물리 안정도(평균/최소 안정도 %) 수치 피드백 연동.
- **[후보 2] 궤적 위상 데이터 파일 내보내기 (Export Trajectory Data)**:
  - 생성 및 물리 최적화된 궤적의 32단계 위상 데이터를 세 가지 규격으로 원클릭 내보내기 지원.
  - C/C++ Header (*.h): 임베디드 펌웨어 및 아두이노/FPGA에 바로 삽입 가능한 PROGMEM 2차원 배열 코드 자동 생성.
  - CSV Spreadsheet (*.csv): 엑셀 및 데이터 분석용 스텝별 3D 좌표, 적응형 딜레이(ms), 트랜스듀서별 위상 매트릭스.
  - Hardware Binary (*.bin): 고속 전송을 위한 0xFA 헤더 - 채널별 위상 바이트 - 0xFD 테일 구조의 하드웨어 전송 패킷 저장.
- **[후보 4] k-Wave 연계 반사판/터널 기구물 음향 전파 및 정재파 시뮬레이션 (k-Wave FDTD Simulation)**:
  - 기구물 기하 형상 모델링: 상단 평면 반사판(Top Reflector), 좌우 가이드 터널(Acoustic Guide Tunnel), 밀폐형 챔버(Enclosed Chamber Box), 개방 공간(Free Field) 지원.
  - 7종 재질 선택기(Material Selector): 아크릴(PMMA, 반사율 ~99.97%), 알루미늄(~99.99%), 스테인리스 스틸(SUS304), 3D 프린팅 수지(PLA/ABS), 유리, 흡음재(Acoustic Foam), 사용자 정의(Custom 밀도/음속/감쇠 직접 입력).
  - 40kHz 다채널 위상 소스 합성: 현재 메인 뷰어의 3D 트랜스듀서 배열 및 위상 데이터를 2D 슬라이스(XZ/YZ) 평면에 매핑하여 연속 정재파 생성.
  - 의사스펙트럼 시간영역(k-space FDTD) 수치 안정화: 고체-공기 계면 스무딩 및 적응형 CFL/PML 경계 조건 적용으로 수치 발산(NaN) 원천 방지.
  - 실시간 비동기 백그라운드 해석: QThread 기반 논블로킹 연산, 진행률(%) 피드백, 취소(Cancel) 제어.
  - 다각도 시각화 및 엔지니어링 분석: 정재파 음압 진폭(|P|) 히트맵, 중심축 음압 프로파일 및 부상 트랩 노드 검출, 순간 음압 파면(Wavefront), 4단계 공학 진단 등급 표기.
  - 결과 데이터 내보내기: 고해상도 시뮬레이션 플롯(*.png) 및 격자 음압 데이터(*.csv, *.npz) 저장.
- **실시간 단면 시각화 내 '순간 파면 (Instantaneous Wavefront)' 모드 신설**:
  - k-Wave 연산 없이 기존 점음원 복소 적분(Numba/Taichi/PyTorch/C++) 엔진의 실수부(Re{P})를 활용하여 0.01초 만에 실시간으로 음파의 마루(압축, 빨간색)와 골(팽창, 파란색) 파면을 3D 평면상에 가시화.
  - 단면 슬라이더나 제어점을 조작할 때도 끊김 없이 3D 뷰어 상에 즉각적인 물결무늬 음향 파면 렌더링.

### 단면 시각화 동적 바운딩 박스 개선 (Dynamic Field Bounds)
- **단면 계산 바운딩 박스 동적 확장 (`_get_field_bounds`)**: 트랜스듀서 중심 좌표뿐만 아니라 배치된 모든 제어점(Control Points)의 3D 좌표를 합산하여 바운딩 박스를 동적으로 생성. 제어점 높이($Z \ge 50\,\text{mm}$)나 측면 이동 시 단면 그리드가 잘리던 문제를 근본적으로 해결하고, 단면 슬라이더는 사용자의 수동 조작 기준을 유지.
