### 2026-10-07 Ultraino 이식 T4 Kinoforms·다중 트랩 완료
- Creo R2 8면·8기판·기판당32개·총256채널을 유지하고 hologram.py에 Focus/Twin/Standing Wave 가상점, 목표 상대 음압·π 위상 제약, 전방/공액 역전파 IBP를 구현했다. T2 전파·합산을 재사용하고 고정 음원 이득과 위상만 조절하는 구동을 구분한다. Java Y→터널 Z의 오른손 좌표 변환 및 원본 중심 기준 ±λ/1.5, ±λ/2를 확인했다.
- 음장 탭의 다중 트랩 설계 창에서 트랩별 타입·가중치·세계 방향, 초기 위상·반복 설정, 잔차·균일도, 현재 배열 위상 적용·설계 JSON 저장·선택 후보의 T3 고정 위상 분석을 연결했다. 메인 Kinoforms 계산은 한 worker/마지막 대기 요청 방식이며 현재 입력 해시가 다른 결과는 폐기한다. Qt/VTK 갱신은 GUI 스레드, 취소·닫기·Escape는 worker 종료 후 처리한다.
- 프로젝트와 Undo/Redo에 설정·트랩 메타데이터·제어점 활성 체크를 저장한다. 비원점 제어점 복원 시 mesh 중심과 actor 이동이 중복되던 오류를 수정했다. 위상은 복원 후 재계산하며 현재 위상 초기값의 정확한 재실행은 설계 JSON의 initial_phases_rad를 사용한다. 단일 이동 목표 궤적의 기존 동기 경로는 유지하며 일반 조작·다중 입자 이송은 T6 범위다.
- 검증: 전체 pytest 171 passed, 3 skipped, 1 warning (12.58s). 기존 OpenJDK25.0.4.1로 수정하지 않은 원본 Kinoforms.java와 공통 점음원 어댑터를 컴파일·12회 반복하여 3타입을 비교했다. 최대 공통 위상 정렬 phasor 오차2.05e−7. Creo256채널 3모델×3타입×4엔진 요청36건에서 CPU/C++/실제 Taichi CUDA 일치, Torch는 CUDA 없는 환경에서 CPU 전환; 최대 phasor오차2.89e−14/복소음장 상대오차1.44e−15.
- 고정 위상 T3 진단18건의 h 수렴·전체 K·힘·미보정 평형 보류를 기록했다. 예시0.25mm EPS 조건에서 두 목표 모두 Focus/Twin은 비복원, Z Standing Wave는 국소 복원 부호였다. 조건부 소프트웨어 결과이며 실제 평형·부양 성공은 아니다. 잔차는 반복에 따라 단조 감소를 보장하지 않고 위상 정체도 최적해를 뜻하지 않는다.
- 실제 Qt 메인 창에서 Creo256·혼합 트랩 적용·선택 후보 T3 분석·오래된 결과 폐기·설정/목표/비활성 체크 복원·계산 중 종료를 확인했다. 설계 창 PNG는 확인했으나 offscreen 3D 뷰포트 캡처·실제 보드·부양·k-Wave는 검증하지 않았다. 단일 CPU 점음원 캐시 사용 사례4.4~8.6ms는 통제된 벤치마크가 아니며 GPU 최초 컴파일과 작은 행렬 호출 비용을 별도 해석해야 한다.
- 기존 Anaconda/NumPy/SciPy/Qt/T2 DLL 및 기존 JDK를 재사용했다. 추가 설치·환경 생성·CAD 재생성·DLL 재빌드·backup 갱신을 하지 않았다. T0~T3는 사용자 요청으로 00de06b를 main에 push했고 이번 T4 변경은 아직 commit/push하지 않았다. 관련 없는 Creo std.out은 보존했다.
- 상세 및 다음 T5 통신·캘리브레이션 인계: docs/ultraino_t4_result.md. 수치/원본Java/Qt/정적 JSON·JUnit·PNG·재현 스크립트는 scratch/ultraino_migration에 있다. 실제 개구·입자 물성·음압 보정 및 컨트롤러/펌웨어/배선 확정은 남아 있다.

### 2026-10-07 Ultraino 이식 T3 고정 위상 방사력 분석 완료
- force_analysis.py에 입자 반경·밀도·음속/직접 압축률·출처, 읽기 전용 FieldSnapshot, 고르코프 U/F와 전체 3×3 복원행렬 K=−∂F/∂x를 추가했다. T2 전파를 재사용하며 현재 위상/진폭을 고정하고 수신 위치만 이동한다. Creo R2의 8면·8기판·32개/기판·256채널 및 실제 방사면/법선을 유지한다.
- 4차 정확도 미분과 h·h/2·h/4 수렴, 전체 K 고유값의 복원/비복원/보류를 계산한다. 대각 성분이 양수여도 결합 방향 saddle을 구별한다. 근접 스텐실·수렴 실패·작은 구 진단 범위 초과·NaN/Inf·잘못된 입력은 부양 판정으로 처리하지 않는다.
- 음장 탭에 고정 위상 분석 창을 연결했다. XYZ 힘·상대 음압·퍼텐셜·축 K 곡선, 전체 행렬·고유값·명목 중력 잔류력 및 실제 엔진을 표시한다. 수치 worker는 Qt/VTK를 접근하지 않는다. 취소·닫기·Escape는 thread 종료 후 닫고 입력 변경/실패/취소는 이전 결과의 저장을 해제한다. 설정은 프로젝트·Undo/Redo, 분석은 입력 스냅샷을 포함한 JSON으로 저장한다.
- 기본 반경0.25mm/밀도25kg/m³/음속2350m/s는 예시 물성이다. 음압은 미보정 상대값, N*·J*는 상대 음압1=1Pa 가정값이다. 중력 mg 합성은 명목 스케일 조건부 결과이며 실제 평형/부양 판정은 보류한다. 기존 궤적 relative_stiffness_norm과 구분한다. 대상 입자·실측 개구·음압/위상 보정은 미확정이다.
- 검증: 전체 pytest 143 passed, 3 skipped, 1 warning (8.98s). 독립 정상파 해석식·Ultraino 계수·3모델 Levitate U/F/K·Creo 강체 변환·결합 saddle·명목 XYZ 평형 조건·미분 수렴/실패·고정 위상/취소·Qt worker 종료/JSON/설정 복원을 확인했다. 256채널 3모델×4엔진 요청12건에서 CPU/C++/실제 Taichi CUDA 일치, 최대 상대 오차 F1.67e−12/K5.34e−11. PyTorch는 현재 CUDA 불가로 CPU 전환하고 해당 GPU 테스트3개는 skip했다.
- 실제 Qt 메인 창의 Creo256채널 Twin Trap/C++ 분석과 캡처를 확인했다. 고정 위상은 분석 전후 같았다. 중심 K는 명목 국소 복원 부호지만 가정 중력 잔류력 Z−1.60e−8N*로 평형이 아니다. 기존 Anaconda/필수 의존성10개/T2 DLL을 재사용했으며 설치·환경 생성·DLL 재빌드를 하지 않았다.
- 상세 및 T4 인계: docs/ultraino_t3_result.md. 수치/Qt/정적 JSON·JUnit·PNG·재현 도구는 scratch/ultraino_migration에 있다. 실제 보드 송신·부양, CAD 재생성, k-Wave 및 Qt offscreen 3D 뷰포트 캡처는 검증하지 않았다. backup/commit/push는 갱신하지 않았다. 다음은 T4 Kinoforms·다중 트랩이다.

### 2026-10-07 Ultraino 이식 T2 공통 음장·방향성 완료
- field_model.py의 SI Green 행렬에 Creo 방사면 위치·실제 법선·개구·진폭을 연결했다. 무지향/Ultraino sinc/원형 피스톤을 구분하고 sin(x)/x의 NumPy π 규약과 원본 지름→반경 변환을 검증했다. 기존 ±Z 법선 추정·5mm 유효 반경 고정·Levitate 기본 음속/p0 의존을 제거했다.

- 검증: 전체 pytest 116 passed, 3 skipped, 1 warning. 세 전파 모델의 SI·방향성·Levitate 음압 비교, Creo 256채널 대칭·법선·강체 변환, CPU/native/Taichi 위상·복소장, 근접 특이점/오류/실패 진단, 모델 저장·Undo/Redo 및 내보내기 프레임 일치. 실제 Qt 창에서 미확정 오류·세 모델·14,400점 단면·저장/복원과 독립 VTK 렌더링도 확인했다.
- 상세: docs/ultraino_t2_result.md. 재현 도구·JSON·JUnit·PNG는 scratch/ultraino_migration에 있다. 테스트 개구는 합성 값이며 실제 반경은 미확정이다. 음압은 상대값, stiffness는 미보정 명목 스케일이다. 실제 보드 송신·부양, CAD 재생성, k-Wave 실행 및 Qt offscreen 뷰포트 캡처는 검증하지 않았다. backup/commit/push는 갱신하지 않았다. 다음은 T3 고정 위상 방사력·방향별 복원성·입자 조건·미분 수렴 검증이다.

### 2026-10-07 Ultraino 이식 T0 계산·송신·내보내기 정합화 완료
- 궤적 최적화와 내보내기의 뒤집힌 C++ 좌표 호출을 PhaseEngine 공통 진입점으로 교체했다. 현재 연산 모드와 송신기 진폭을 사용하며 DLL 부재 시 NumPy 경로를 사용한다. 입력·계산 결과의 채널 수와 유한값을 검사한다.
- 실패·빈 입력·영 트랩 강도에는 valid=False와 점수 None을 반환한다. 궤적 목록, 상태바, 진단 카드에 진단 불가를 표시하며 저장된 이전 Fallback의 75/60% 점수도 숨긴다. 성공 표시는 모델 상대 강도로 제한한다.
- HardwareController에 소프트웨어 순서 위상 보정 후 물리 채널 맵 적용 경로를 모았다. 송신과 헤더/CSV/바이너리 내보내기가 이를 공유한다. 일반 .bin은 선택 프로파일의 실제 프레임, 이전 0xFA 파일은 .legacy.bin이다. 바이너리에 스텝 지연은 포함되지 않는다.

  - C/C++ Header (*.h): 임베디드 펌웨어 및 아두이노/FPGA에 바로 삽입 가능한 PROGMEM 2차원 배열 코드 자동 생성.
  - CSV Spreadsheet (*.csv): 엑셀 및 데이터 분석용 스텝별 3D 좌표, 적응형 딜레이(ms), 트랜스듀서별 위상 매트릭스.
  - Hardware Binary (*.bin): 고속 전송을 위한 0xFA 헤더 - 채널별 위상 바이트 - 0xFD 테일 구조의 하드웨어 전송 패킷 저장.
- **[후보 4] k-Wave 연계 반사판/터널 기구물 음향 전파 및 정재파 시뮬레이션 (k-Wave FDTD Simulation)**:
  - 기구물 기하 형상 모델링: 상단 평면 반사판(Top Reflector), 좌우 가이드 터널(Acoustic Guide Tunnel), 밀폐형 챔버(Enclosed Chamber Box), 개방 공간(Free Field) 지원.
  - 7종 재질 선택기(Material Selector): 아크릴(PMMA, 반사율 ~99.97%), 알루미늄(~99.99%), 스테인리스 스틸(SUS304), 3D 프린팅 수지(PLA/ABS), 유리, 흡음재(Acoustic Foam), 사용자 정의(Custom 밀도/음속/감쇠 직접 입력).
  - 40kHz 다채널 위상 소스 합성: 현재 메인 뷰어의 3D 트랜스듀서 배열 및 위상 데이터를 2D 슬라이스(XZ/YZ) 평면에 매핑하여 연속 정재파 생성.
  - 의사스펙트럼 시간영역(k-space FDTD) 수치 안정화: 고체-공기 계면 스무딩 및 적응형 CFL/PML 경계 조건 적용으로 수치 발산(NaN) 원천 방지.
  - 실시간 비동기 백그라운드 해석: QThread 기반 논블로킹 연산, 진행률(%) 피드백, 취소(Cancel) 제어.
  - 다각도 시각화 및 엔지니어링 분석: 정재파 음압 진폭(|P|) 히트맵, 중심축 음압 프로파일 및 부상 트랩 노드 검출, 순간 음압 파면(Wavefront), 4단계 공학 진단 등급 표기.
  - 결과 데이터 내보내기: 고해상도 시뮬레이션 플롯(*.png) 및 격자 음압 데이터(*.csv, *.npz) 저장.
- **실시간 단면 시각화 내 '순간 파면 (Instantaneous Wavefront)' 모드 신설**:
  - k-Wave 연산 없이 기존 점음원 복소 적분(Numba/Taichi/PyTorch/C++) 엔진의 실수부(Re{P})를 활용하여 0.01초 만에 실시간으로 음파의 마루(압축, 빨간색)와 골(팽창, 파란색) 파면을 3D 평면상에 가시화.
  - 단면 슬라이더나 제어점을 조작할 때도 끊김 없이 3D 뷰어 상에 즉각적인 물결무늬 음향 파면 렌더링.
