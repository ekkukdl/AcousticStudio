   - Windows 압축 해제 시 발생한 한글 깨짐 및 주석 삼킴 현상 100% 정상화.
2. **UI/UX 개선 및 스크롤바, 정렬 최적화** (완료)
   - 오버레이 스크롤바 도입 및 QSplitter를 통한 화면 잘림/찌그러짐 방지 적용.
   - 좌표/각도(X, Y, Z / Rx, Ry, Rz) 입력칸 QGridLayout 칼각 정렬 완료.
3. **객체 속성 실시간 능동 조절 기능 (Properties Panel)** (완료)
   - 초음파 센서 종류 실시간 교체(Morphing) 및 타겟 반경 조절.
4. **마우스 피킹 오류 및 빈 공간 클릭 시 튕김(ZeroDivisionError) 완벽 수정** (완료)
   - 들여쓰기 꼬임으로 인한 0으로 나누기 오류 수정.
5. **3D 기즈모(Gizmo) UI 조작계 구축** (완료)
   - vtkAxesTransformWidget을 적용하여 선택한 객체(단일/다중)에 X, Y, Z 드래그 화살표 표시.
   - 마우스 드래그 이동과 우측 패널의 SpinBox 숫자가 실시간으로 상호 연동되도록 Two-way Binding 성공적 구현.

6. **Clear All 버그 수정** (완료)
   - Clear all 실행 시 객체는 지워지나 기즈모 UI가 화면에 남는 현상을 해결하기 위해 clear_view에 self.on_selection_changed() 호출을 추가하여 기즈모를 숨김 처리함.

7. **Tube 어레이 안쪽 방향(Inward-facing) 정렬 수정** (완료)
   - Tube 생성 시 트랜스듀서들이 바깥쪽(Outward)을 향하던 회전 각도 오류(cAngle_deg + 180)를 180 - cAngle_deg로 수정하여, Ultraino 프로그램과 동일하게 원통의 중심을 향하도록(Inward) 정상적으로 배치되게 함.

8. **하드웨어 실시간 통신 UI (USB Serial) 구현** (완료)
   - 사용자가 직접 타이핑하는 방식 대신, 현재 연결된 COM 포트를 자동으로 스캔하여 드롭다운으로 표시하고 선택하도록 UI(QComboBox) 개선
   - 아두이노/제어 보드에서 흔히 쓰이는 통신 속도(9600, 115200 등)를 리스트화하여 선택할 수 있도록 적용
   - 포트 새로고침 버튼(↻) 추가하여 실행 중에도 포트 재검색 가능

9. **하드웨어 실시간 연동 제어 활성화** (완료)
   - 3D 기즈모를 드래그하거나 좌표를 변경할 때 즉각적으로 위상을 재계산하고 시리얼 패킷(Serial Packet)을 전송하는 실시간 자동 연동 기능을 기본적으로 활성화(uto_calc_cb -> True)하여, PC 화면과 실제 하드웨어가 1:1로 실시간 동기화되도록 함.

10. **실시간 이송 제어 랙(Lag) 현상 및 버벅임 최적화** (완료)
    - 마우스 드래그 중 매 프레임마다 콘솔에 출력되던 print 로그가 GUI 스레드를 블로킹(I/O 병목)하여 버벅임을 유발하는 현상 제거
    - 텍스트 출력 제거를 통해 빠르고 부드러운 하드웨어 실시간 연동 제어가 가능하도록 로직 최적화

11. **초음파 배열 간격(Spacing) UI 추가 및 위상 연산 벡터화(Vectorization)** (완료)
    - Ultraino의 간격 조절 기능을 반영하여 배열 생성 시 트랜스듀서 간의 간격(Spacing)을 사용자가 직접 입력(QDoubleSpinBox)할 수 있도록 UI(하단 패널)에 추가함. 센서 종류를 변경하면 기본 권장 간격으로 자동 변경됨.
    - 실시간 위상 연산(simulate_colors) 알고리즘의 내부 파이썬 루프를 제거하고 **NumPy 배열 기반 벡터화 연산(Vectorized Array Operations)**으로 전면 교체. 이로써 계산 정확도를 100% 유지하면서도 실시간 3D 제어 연산 속도가 기존 대비 최대 100배 이상 비약적으로 빨라짐.

## 🎯 남은 과제 및 향후 개발 목표 (To-Do)

### 1. 소프트웨어(AcousticStudio) 핵심 기능 추가
- **[BugFix] 3D 기즈모(화살표) 시각화 문제**: PyVista 뷰포트 내에서 vtkAxesTransformWidget이 렌더링되지 않고 투명화되는 현상 해결 (우선순위: 낮음).
- **C++ 기반 연산 가속**: 현재 파이썬(NumPy) 기반의 위상 계산을 C++ 모듈로 포팅하여 실시간 제어를 위한 초고속 연산 확보.

### 2. 하드웨어 및 알고리즘 고도화
- **하단 고출력 랑주뱅 진동자(Langevin) 도입**: 무거운 물체 부양을 위해 하단에 60W 랑주뱅 진동자를 배치하고, 상단에 소형 배열과 중첩(Superposition)시키는 하이브리드 연산 추가.
- **선형 이송(Linear Transport) 최적화 경로**: 복잡한 360도 회전 대신, 대상 부양체를 안정적으로 직진 이동시키는 데 집중하는 궤적 최적화 모드 구현.
- **터널형(4면) 배열 자동 캘리브레이션**: 직교 간섭을 막기 위해 마주보는 배열 간의 거리가 '반파장의 정수배'가 되도록 자동 계산하는 기능 추가.
- **Z축 캡슐화 트랩(Encapsulation)**: 개방된 Z축 방향으로 초음파가 새어나가 부양체가 흔들리는 현상을 막는 특수 트랩 알고리즘 적용.
- **카메라 피드백 기반 PID 제어**: OpenCV 기반으로 부양체의 실제 위치를 추적하여 오차를 보정하는 폐루프(Closed-loop) 제어 구현.
- **하드웨어 설계**: L298N 모터 드라이버를 대체하는 새로운 소형 PCB 설계 및 소규모 PoC(개념 증명) 제작.

- [진행 중] [2순위] 하이브리드 터널 자동 생성: Ultraino 코드를 분석하여 Tube 형태의 3D 진동자 배열 자동 생성 로직 분석 및 포팅 진행 중.
