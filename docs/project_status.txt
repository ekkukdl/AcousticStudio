# AcousticStudio 프로젝트 상태 및 계획

## 1. 최근 해결된 문제 및 구현 완료 기능 (Completed)
- **PyVista 기반 3D 실시간 렌더링 뷰어 완성**: 트랜스듀서 배열 및 제어점을 직관적으로 조작할 수 있는 환경 구축. 배열 초기화(Clear All) 시 30초 이상 걸리던 랙 현상을 0.4초 이하로 최적화 완료.
- **다중 가속 연산 엔진 통합**: Numba(CPU), C++ DLL, Taichi(GPU), PyTorch(GPU) 등 하드웨어 가속 다중 연산 모드를 지원하며, 사용자 환경에 맞춰 최적의 엔진을 자동 선택.
- **오프라인 궤적(Trajectory) 및 시뮬레이션 시스템**: 객체를 시작점에서 목표점까지 옮기는 3D 궤적(Linear Transport) 애니메이션 생성, 미디어 컨트롤러, 궤적 리스트 관리 기능 완비.
- **하드웨어 제어 (보드 연동)**: 시뮬레이션 위상 데이터를 Serial Port를 통해 실제 보드로 실시간 전송 (SonicSurface 기반 32단계 위상 분할 패킷 적용).
- **UI/UX 편의성 고도화**:
  - 상태 표시줄에 실시간 CPU/GPU 리소스 모니터링 메뉴 추가.
  - 보기 메뉴에 서브 메뉴(화면 설정)를 도입하고, 항목 클릭 시 메뉴가 닫히지 않고 열림 상태를 유지하도록 KeepOpenMenu 커스텀 클래스 적용.
  - QSettings를 연동하여 CPU/GPU 모니터링 옵션 상태(On/Off) 영구 저장 유지.
  - psutil, GPUtil 라이브러리 자동 설치 지원 및 라이브러리 관리자 추가 연동.
  - 작업 내용이 저장되지 않았을 경우 팝업되는 자동 경고창 추가.
- **팝업 UI 줄바꿈 및 레이아웃 최적화**:
  - 알림/경고 다이얼로그(show_silent_msg)의 최소 너비를 기존 350px에서 420px로 확장하여, 단어 하나만 다음 줄로 밀려나던 고립 줄바꿈 현상 원천 해결.
  - 텍스트 라인 간격(line-height: 140%) 및 버튼 여백을 최적화하고, 창 닫기 시 저장 확인 문구를 '종료하기 전에 변경사항을 저장하시겠습니까?'로 자연스럽게 정돈.
- **궤적 물리 안정성 진단 고도화 (이모지 배제 및 공학 4단계 등급화)**:
  - 이모지를 완전히 배제하고 신뢰성 높은 공학적 4단계 등급 체계 구축: 최적(85%+), 안정(60~84%), 주의(40~59%), 위험(<40%).
  - 궤적 리스트 명칭 간소화: '[선형]: ... [안정 65%]', '[일반 등속]' 형태로 깔끔하게 표기.
  - 우측 패널에 '물리 안정성 진단 미니 요약 카드'를 신설하여 궤적 선택 시 실시간 등급, 평균/최저 안정도, 공학 가이드 코멘트(적응형 감속 적용 여부, 딜레이 권장 등)를 한눈에 제공.
- **levitate 물리 연산 기반 선형 이송 궤적 최적화 구현**:
  - mm ↔ m 물리 단위계 정합화(1,000배 단위 오차 원천 해소).
  - PhaseEngine 내에 optimize_trajectory_physical 모듈을 구축하여 경로상 각 웨이포인트에서의 3차원 음향 복원력 스티프니스(Radiation Force Stiffness) 및 트랩 강도를 정밀 연산.
  - 트랩 강도 취약 구간에서의 적응형 지연시간(Adaptive Delay) 동적 배분 및 급가속/급감속 관성 이탈 방지를 위한 S-curve(Cosine ramp) 가감속 스무딩 적용.
  - 궤적 리스트 및 하단 상태 표시줄에 실시간 물리 안정도(평균/최소 안정도 %) 수치 피드백 연동.

- **오프라인 하드웨어 실시간(Real-time) 제어 모드 추가**: '실시간 전송' 체크박스를 추가하여, 프로그램상에서 제어점(공)을 움직일 때마다 연결된 보드로 즉각 위상 데이터가 전송되도록 구현.
- **하드웨어 연결 UI 및 사용성 개선**: 
  - COM 포트 선택창이 좁아 글씨가 잘리는 현상을 수정 (minimumWidth(80)).
  - 연결 성공 시마다 울리던 윈도우 알림 및 팝업창을 제거하여 쾌적한 사용 환경 조성 (실패 시에만 알림 팝업 유지).
- **시뮬레이션 재생 컨트롤러 및 궤적 리스트 UI 개편**: 
  - 미디어 컨트롤 버튼(재생, 정지 등)에 텍스트 이모지 대신 Qt 기본 네이티브 아이콘(QStyle.StandardPixmap)을 적용하여 깔끔하고 전문적인 디자인으로 개선.
  - 궤적 리스트를 '궤적 생성' 버튼과 '삭제' 버튼 사이에 직관적으로 배치 및 삭제 버튼(선택/모든) 사이즈/색상 통일.
- **설정 패널 스크롤 휠 방지**: 우측 설정 패널에서 휠 스크롤 시 슬라이더(QSlider) 값이 의도치 않게 변경되는 현상을 차단.
- **음압 단면 숨기기 버그 수정**: 캐싱된 그래픽 자원이 화면에 남지 않도록 완벽하게 초기화(clear) 적용.

### 모듈 분리 리팩터링 완료 (Module Separation Refactoring)
- **app.py 모듈 분리 완료 (3,126줄 → ~2,655줄)**: 모놀리식 app.py에서 독립적인 6개 모듈로 코드를 분리하여 유지보수성과 확장성을 대폭 향상.
  - `widgets.py` (~360줄): ResourceMonitorThread, MouseEventFilter, WheelBlocker, KeepOpenMenu
  - `phase_engine.py` (~153줄): PhaseEngine 클래스 (위상 연산 + 음압 분포 계산), calculate_field_slice_numba
  - `hardware.py` (~152줄): HardwareController 클래스 (시리얼 연결/해제/패킷 전송, 시그널 기반)
  - `state_manager.py` (~60줄): StateManager 클래스 (Undo/Redo 스택 관리)
  - `file_io.py` (~11줄): 프로젝트 JSON 저장/불러오기 순수 함수
- **설계 원칙**: 하위 모듈은 상호 import 없음. 모든 모듈 간 통신은 app.py의 시그널/슬롯 연결을 통해 이루어짐.
- **기존 코드 백업**: AcousticStudio/backup/ 폴더에 원본 파일 보관.
