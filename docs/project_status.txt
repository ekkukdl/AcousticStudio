# AcousticStudio 프로젝트 상태 및 계획

## 1. 최근 해결된 문제 및 구현 완료 기능 (Completed)
- **PyVista 기반 3D 실시간 렌더링 뷰어 완성**: 트랜스듀서 배열 및 제어점을 직관적으로 조작할 수 있는 환경 구축. 배열 초기화(Clear All) 시 30초 이상 걸리던 랙 현상을 0.4초 이하로 최적화 완료.
- **다중 가속 연산 엔진 통합**: Numba(CPU), C++ DLL, Taichi(GPU), PyTorch(GPU) 등 하드웨어 가속 다중 연산 모드를 지원하며, 사용자 환경에 맞춰 최적의 엔진을 자동 선택.
- **오프라인 궤적(Trajectory) 및 시뮬레이션 시스템**: 객체를 시작점에서 목표점까지 옮기는 3D 궤적(Linear Transport) 애니메이션 생성, 미디어 컨트롤러, 궤적 리스트 관리 기능 완비.
- **하드웨어 제어 (보드 연동)**: 시뮬레이션 위상 데이터를 Serial Port를 통해 실제 보드로 실시간 전송 (SonicSurface 기반 32단계 위상 분할 패킷 적용).
- **UI/UX 편의성 고도화**:
  - 상태 표시줄에 실시간 CPU/GPU 리소스 모니터링 메뉴 추가.
  - 보기 메뉴에 서브 메뉴(화면 설정)를 도입하고, 항목 클릭 시 메뉴가 닫히지 않고 열림 상태를 유지하도록 KeepOpenMenu 커스텀 클래스 적용.
  - QSettings를 연동하여 CPU/GPU 모니터링 옵션 상태(On/Off) 영구 저장 유지.
  - psutil, GPUtil 라이브러리 자동 설치 지원 및 라이브러리 관리자 추가 연동.
  - 작업 내용이 저장되지 않았을 경우 팝업되는 자동 경고창 추가.

## 2. 현재 진행 상황 (Current Status)
- 기반이 되는 통합 컨트롤 UI 화면(Acoustic Control Studio) 및 렌더링 프레임워크가 궤도에 올랐음.
- SonicSurface 및 Ultraino 레퍼런스에 기반한 하드웨어 통신과 위상 변조 수식이 성공적으로 안착됨.
- 향후 최적화 기능을 위한 levitate 엔진 및 물리 연산 뼈대가 구조적으로 준비됨.

## 3. 진행해야 할 부분 (To-Do)
- [ ] **최적화된 선형 이송 궤적 (Linear Transport Optimized Trajectory) 기능 고도화**:
  - 단순 좌표 기반의 선형 이동을 넘어, 초음파 부상 중 물체가 떨어지지 않고 안정적으로 이동할 수 있도록 포획력(Force)과 음압(Pressure)을 촘촘히 연산하는 궤적 최적화 로직 개발.
  - 이 과정에서 levitate 또는 k-wave 라이브러리의 Acoustic Radiation Force 연산 모델링 및 정밀 음압 전파 엔진을 백엔드에 본격적으로 통합하여 물리적 정확도를 극대화할 예정.


### 최근 업데이트 내역 (UI/UX 개선 및 버그 수정 완료)
- **물리 기반 궤적 최적화 버그 수정**: levitate 라이브러리의 TransducerModel 대신 공간 미분을 지원하는 CircularPiston(effective_radius=0.005) 클래스를 사용하도록 수정하여 최적화 계산 실패 에러 해결.
- **오프라인 하드웨어 실시간(Real-time) 제어 모드 추가**: '실시간 전송' 체크박스를 추가하여, 프로그램상에서 제어점(공)을 움직일 때마다 연결된 보드로 즉각 위상 데이터가 전송되도록 구현.
- **하드웨어 연결 UI 및 사용성 개선**: 
  - COM 포트 선택창이 좁아 글씨가 잘리는 현상을 수정 (minimumWidth(80)).
  - 연결 성공 시마다 울리던 윈도우 알림 및 팝업창을 제거하여 쾌적한 사용 환경 조성 (실패 시에만 알림 팝업 유지).
- **시뮬레이션 재생 컨트롤러 및 궤적 리스트 UI 개편**: 
  - 미디어 컨트롤 버튼(재생, 정지 등)에 텍스트 이모지 대신 Qt 기본 네이티브 아이콘(QStyle.StandardPixmap)을 적용하여 깔끔하고 전문적인 디자인으로 개선.
  - 궤적 리스트를 '궤적 생성' 버튼과 '삭제' 버튼 사이에 직관적으로 배치 및 삭제 버튼(선택/모든) 사이즈/색상 통일.
- **설정 패널 스크롤 휠 방지**: 우측 설정 패널에서 휠 스크롤 시 슬라이더(QSlider) 값이 의도치 않게 변경되는 현상을 차단.
- **음압 단면 숨기기 버그 수정**: 캐싱된 그래픽 자원이 화면에 남지 않도록 완벽하게 초기화(clear) 적용.


### 추가 UI/UX 개선 및 깃허브 백업 내역 (2차)
- **팝업창 소리 및 디자인 전면 개편**: 윈도우의 시끄러운 기본 에러음 대신 커스텀 무음 팝업창을 도입하고, 부드러운 알림음(QApplication.beep)만 울리도록 쾌적화. 원시적인 에러 코드(FileNotFoundError 등) 대신 사용자 친화적인 안내 문구로 교체.
- **물리적 연결 해제 자동 감지**: 보드 선이 물리적으로 뽑혔을 때 이를 1초 단위 백그라운드 타이머로 실시간 감지하고 UI를 원래 상태로 복구하는 기능 추가.
- **실시간 전송 로직 단일화**: 궤적 시뮬레이션의 중복 전송(Double-send) 문제를 해결하기 위해 불필요한 위상 전송 체크박스를 삭제하고 마스터 '실시간 전송' 스위치로 완벽하게 통합.
- **UI 레이아웃 및 잘림 현상 해결**:
  - '배열 이동/회전' 부분의 글자가 겹치던 현상 수정 (라벨 간소화).
  - 궤적의 '예상 소요 시간' 라벨을 미디어 플레이어 쪽으로 직관적으로 재배치하고, 시간이 길어져도 글자가 잘리지 않도록 레이아웃 재구성 및 실제 딜레이 계산 로직 적용.
  - 상단 메뉴 클릭 시 우측 하단의 CPU/GPU 사용량 텍스트가 깜빡이거나 사라지는 현상을 Permanent Widget으로 고정하여 완벽하게 해결.
