# 2026-10-07 저장소 통합

최종 GitHub 저장소와 로컬 작업 폴더는 `AcousticStudio`입니다. 내부 파일의 기준은 ver2의 커밋 `719ebd00a79faf92653e92bea007ed420f6375ff`입니다. 이 커밋은 ver2의 기존 GitHub 커밋 `2417356`에 클래식/모던 UI 선택, DOILLABS 업로드 자료 수정, 구상도 재정리와 관련 로컬 작업을 포함합니다.

기존 저장소의 마지막 커밋 `197962c`와 ver2 이력을 병합 커밋의 두 부모로 보존합니다. 파일을 복사하여 이력을 새로 시작하거나 기존 main을 강제로 교체하는 방식은 사용하지 않습니다. 파일 트리는 ver2를 기준으로 하며 이 README와 통합 기록만 추가 정리했습니다.

## 포함된 작업

- 초음파 위상 계산, 음장/궤적 제어, k-Wave, 보드 통신 코드와 기존 진행 문서.
- 보기 → UI → 클래식/모던 전환, 마지막 선택 저장, 공통 보드 메뉴.
- 구상도 전체 추적 자료: 초기/최신 PCB, Gerber, BOM/PnP, DOILLABS 원본 템플릿 및 업로드 수정본, 부품 조사, 회로 검토 자료.
- 32채널 PCB R1 및 8면 256채널 배치, Creo 모델과 외부 프레임 R2, 미리보기, 생성/검증 기록.
- 구상도 폴더 재정리, 시작 안내, 작업 스크립트 및 요청에 따라 만든 UI 수정 전 백업.

ver2의 추적 파일 전체를 대조하고, CAD/제작 산출물 및 UI 백업은 실제 바이트와 SHA-256 보존을 확인합니다. 계산 코드·통신 코드는 원본과 비교했고, Qt 전환 및 보드 프레임 검사와 실제 앱 offscreen 전환 경로를 확인합니다. 자동 검사 결과는 실제 보드·부양 성능 검증을 뜻하지 않습니다.

가상환경, node_modules, PTC 런타임, 세션 로그, 캐시 등 기존 Git 제외 항목은 GitHub 배포에 포함하지 않습니다. 해당 로컬 자료와 원래 `AcousticStudio_ver2` 폴더 및 GitHub 저장소는 보존합니다. 이후 신규 작업과 푸시는 `AcousticStudio`에서 진행합니다. ver2 원격 저장소 삭제나 이름 변경은 수행하지 않습니다.

통합 시점의 원래 main은 로컬 `archive/pre-consolidation-20261007` 브랜치로도 보존했습니다. 파일 대조 결과는 [검증 JSON](repository_consolidation_validation.json)에 기록합니다.

기존에 추적된 Creo 세션 로그 2개는 ver2 로컬 원본 바이트를 그대로 보존했습니다. 과거 Git 저장본과의 차이는 CRLF/LF 줄바꿈뿐입니다. UI 백업의 소스·자산 18개는 해시로 검증했으며 자동 생성 Python 캐시 9개는 배포에서 제외했습니다. 원래 캐시 포함 백업은 ver2 폴더에 보존되어 있습니다.
